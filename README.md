# novel-factory

**长篇小说生成的工程参考实现**——四层规划（卷→弧→段→章）、三账本记忆、候选盲评、伏笔排期清账、时序锚、24 项量化体检。

> 这不是"一键生成小说"的工具，而是一套把长篇连载的工程问题——跨章一致性、伏笔遗忘、节奏失序、
> 进度漂移——拆成**可校验机制**的框架。目标读者：想研究或构建 AI 长篇生成管线的开发者。

## 它解决什么问题

长篇连载（30 万字以上）靠单次提示无法保证质量，真正的难题是**跨章的工程约束**。本项目把每类约束做成机制：

| 长篇难题 | 对应机制 |
|---|---|
| 写到后面人物状态、持有物、时间线自相矛盾 | 三账本（角色/物品/势力）+ 一致性索引 + 时序锚（境界式锁定） |
| 伏笔"埋了就忘"或"埋了立刻收" | 伏笔排期表（PLANNED→PLANTED→PAID 状态机）+ 卷末清账裁决 + 写手视图去元信息 |
| 模型自我修正的同质化陷阱 | 候选盲评：低置信章触发异模型整章重写 + 机械门禁 + 异族评审 |
| "这批比上批是好是坏"无法归因 | 批末体检：24 项量化指标，每项带历史基线与可执行建议 |
| 长跑批的中途失败与人工介入 | 逐章检查点/回滚 + 阶段出口人工审批挂起 |
| 计划与正文的时间/年龄漂移 | 时序锚 v2：计划声明的 timeAdvance 是唯一合法推进通道，审计回验 |

## 快速开始

### 前置

| 依赖 | 说明 | 必需 |
|---|---|---|
| JDK 17+ / Maven 3.9+ | 编译与运行 | ✅ |
| OpenAI 兼容端点 API Key | DashScope / one-api / new-api 均可 | ✅ |
| Qdrant 1.14+ | 向量增强（动态资料/故事记忆检索） | 可选 |

> Qdrant 未启动时系统以"无向量增强"模式运行：文件侧记忆（三账本/摘要/伏笔账）承载全部功能，
> 批末体检的"无检索唤醒章数占比"会提示哪些章是裸跑的。

### 三步启动

1. **配置密钥**（唯一必改项）——二选一：
   - 环境变量：`LLM_API_KEY=sk-你的密钥`
   - 或复制 `config/application-local.example.yml` 到 `novel_factory-app/src/main/resources/application-local.yml` 填入；
2. **启动**：
   ```bash
   mvn spring-boot:run -pl novel_factory-app
   ```
3. **创作**：浏览器打开 `http://localhost:8080`，参考 `sample/story-input.json` 创建故事，提交续写作业。

每批（默认 5 章）结束后看**批末体检报告**——24 项指标 + 可执行建议，这就是本系统的仪表盘。

## 批末体检长什么样

每项指标三列：**当前值 ｜ 目标（含历史基线）｜ 明细**，级别 OK / WATCH / DEGRADED / CRITICAL，尾部附建议。真实示例（节选）：

```text
OK      账本完整度       94.06%（目标 ≥90%） ｜ 严格 523 / 放宽 47 / 挂起 11
OK      对白轮次密度     22.50次/千字（目标 ≥9）
WATCH   候选选优触发率    52%（目标 ≤30%） ｜ 触发 39 / 65 章
DEGRADED 进度对齐        7段（目标 ≤1 段） ｜ 第 65 章按大纲应处【61-70章 2009年/11岁】段
建议：进度滞后约 6 年：……两条出路：①规划层加速（跳月/压缩日常）；
②承认慢节奏，重排大纲章段预算。不应长期维持现状——路标与正文漂移会越滚越大。
```

每条 DEGRADED 都对应一个可执行的下一步——这是本系统与"生成完就结束"的工具最大的区别。

## 架构

六个 Maven 模块：`types`（枚举/值对象）→ `api`（DTO）→ `domain`（全部机制）→ `infrastructure`（文件/向量/LLM 网关）→ `trigger`（HTTP）→ `app`（装配）。

- 存储：**文件仓库**（`docs/workspace/` 下 JSON——正文、摘要、三账本、蓝图、检查点，全部可 git、可手工修）+ Qdrant 向量库（可选增强）
- 详细设计：[架构与机制](docs/architecture.md) ｜ [快速开始](docs/quickstart.md)

## 已知限制

- 面向**中文长篇**设计（分词、账本、体裁模板均以中文假设为前提）；
- 单机文件存储：多机协作、多人共写不在当前范围内；
- 每章生成成本 8-25 万 token（视质量档位）——这是"全链路审校+候选"的定价，预算敏感请调低候选触发；
- 大纲（chapterGoal）需要作者按"章段+时间标记"格式编写，见 `sample/`。
