# 人物塑造原则

好的人物是故事的灵魂。读者记住的是人，不是情节。

## 人物档案模板

每个主要角色都应建立完整档案：

### 基本信息

```text
姓名：（有意义的名字更好）
年龄：
职业：
外貌特征：（2-3个显著特征，避免泛泛而谈）
```

### 性格核心

```text
核心价值观：（他最相信什么）
最大恐惧：（他最害怕什么）
致命缺陷：（什么会导致他失败）
内心渴望：（他真正想要什么）
```

### 背景故事

```text
成长环境：
创伤经历：（过去伤害他的事）
关键记忆：（塑造他现在的关键事件）
秘密：（别人不知道的事）
```

### 行为模式

```text
说话方式：（口头禅、语速、用词习惯）
肢体语言：（习惯动作、紧张时的小动作）
社交风格：（内向/外向、如何对待陌生人）
压力反应：（压力下如何表现）
```

## 人物类型塑造

### 主角（Protagonist）

**必须有：**
- **明确目标** - 他想要什么
- **强大动机** - 为什么想要
- **可共情性** - 读者能理解他的感受
- **成长空间** - 故事中会改变

**主角原型：**
| 类型 | 特征 | 故事作用 |
|-----|------|---------|
| 英雄型 | 勇敢、正义、利他 | 战胜外在威胁 |
| 成长型 | 从弱小到强大 | 克服内在缺陷 |
| 反英雄型 | 道德灰色、复杂 | 挑战传统道德 |
| 平凡型 | 普通人卷入非凡事 | 读者代入感强 |

### 反派（Antagonist）

**好反派的特点：**
- **强大可信** - 不应该是草台班子
- **有自己的逻辑** - 他相信自己在做正确的事
- **与主角有深层联系** - 不是单纯为了作恶
- **揭示主题** - 挑战主角的信念

**反派动机类型：**
- 理想主义扭曲（"为了大局必须牺牲"）
- 过去创伤（"世界伤害了我，我要报复"）
- 权力渴望（"我配得上更多"）
- 与主角相同目标（不同方法）

### 配角（Supporting Characters）

**配角功能：**
- **导师型** - 指引主角，传递信息
- **盟友型** - 协助主角，提供情感支持
- **搞笑型** - 缓解紧张，提供喜剧元素
- **爱情型** - 制造浪漫线索，增加个人利害
- **叛徒型** - 制造背叛和转折

**配角原则：**
- 每个配角必须有明确作用
- 删除"只是存在"的角色
- 避免刻板印象（除非是有意为之）

## 人物深度塑造技巧

### 1. 矛盾性

真实的人是复杂的，充满矛盾。

**示例：**
- 暴力的黑帮成员但爱护流浪猫
- 无神论的牧师
- 害怕黑暗的侦探
- 重视友情但总是背叛朋友

### 2. 侧面揭示

不要直接陈述性格，通过行为展示。

| 错误（直接陈述） | 正确（侧面展示） |
|----------------|----------------|
| 他很愤怒 | 他捏碎手中的纸杯 |
| 她很紧张 | 她反复调整眼镜位置 |
| 他很傲慢 | 他从不直视下属的眼睛 |
| 她很善良 | 她偷偷喂流浪狗三年 |

### 3. 声音独特性

每个人说话方式不同，对话中能分辨角色。

**区分要素：**
- 用词选择（正式/俚语/方言）
- 句子长度
- 是否打断别人
- 是否喜欢隐喻
- 情绪表达方式

### 4. 动机合理化

每个角色行为必须有合理动机，即使动机扭曲。

**反派动机合理化示例：**
- "我想毁灭世界" → 乏味
- "我失去了一切，世界对我没有意义" → 可理解但扭曲
- "人类是地球的病毒，我必须清除" → 有哲学支撑

### 5. 缺陷致命化

主角必须有缺陷，缺陷在关键时刻导致失败。

**经典缺陷模式：**
| 缺陷 | 导致的失败 |
|-----|----------|
| 傲慢 | 低估对手，落入陷阱 |
| 信任问题 | 拒绝帮助，孤立无援 |
| 完美主义 | 无法及时行动，错失机会 |
| 复仇心 | 被利用，失去理智 |

### 6. 反差人设设计

"人前正常，人后痴女/病娇/戏精"类反差角色，需要建立双层人设并控制揭示节奏：

- **表层人设**：角色在公开场合展示的形象（高冷主席、豪爽女汉子、社恐学妹），这是读者和其他角色首先看到的。
- **隐藏人设**：角色独处或情绪失控时暴露的真实属性（痴女、病娇、戏精），这是角色深度和戏剧张力的来源。
- **自然揭示节奏**：隐藏人设不能一次性全部暴露，必须分阶段：
  1. **破绽期**（前 1/3）：通过微小细节暴露（用词破绽、句长变化、下意识动作），读者可能没注意到，但回收时恍然大悟。
  2. **半遮半露期**（中 1/3）：在特定场景（独处、被戳中痛点）较大幅度暴露，但角色会立刻掩饰，掩饰本身就是戏。
  3. **完全暴露期**（后 1/3）：在关键剧情节点完全暴露，且暴露后不再掩饰，角色关系发生质变。
- **避免 OOC**：隐藏人设暴露时，角色的核心价值观和行为逻辑必须一致，不能为了反差而反差；高冷角色可以是痴女，但痴女的表达方式仍然符合她的性格（如默默收集男主物品、而不是主动扑上去）。
- **反差的代价**：隐藏人设暴露必须付出实际代价（关系裂痕、信任损耗、社会评价变化），不能暴露了就当没发生过。

### 7. 习惯性小动作作为身份标记

每个主要角色必须固定 1 个无意识小动作作为身份标记，这是角色辨识度的关键：

- **小动作三特征**：无意识、重复、与当前场景功能无关（如摩挲钢笔、踢桌腿、推眼镜、转笔、咬嘴唇）。
- **情绪定动作家族**：不同情绪下小动作有变化（紧张时加快、愤怒时用力、心动时停顿），但动作本身不变。
- **频率控制**：同一动作每章至多出现 2 次，重要人物可固定一个"习惯性小动作"作为身份标记，但出现频率同样受限（与规则 anti-ai-tone.md 生理反应复读机判据联动）。
- **小动作变化即信号**：当角色的习惯性小动作突然改变或消失时，意味着角色状态发生了重大变化（如紧张到忘了转笔、愤怒到把笔捏断），这是比直接写"他很紧张"更有力的表达。

## 主角完美度校准：全能主角要留缺口

能力可以满点，软肋、盲区、代价必须真实——无缺口的主角无人代入，冲突只能靠反派降智推进。缺口四坐标不必全上，选两样写实即可，全堆上去反而刻意卖惨：

| 支点 | 原理 | 应该怎么写 | 坏写法 |
|------|------|-----------|--------|
| 软肋具体 | 缺口要有坐标 | 定一个会被对手利用的软肋：亲人、承诺、旧伤 | 软肋只存在于回忆 |
| 盲区真实 | 聪明人要有不会的事 | 给一项真实的能力盲区并造成可感知的失败 | 全知全能无不会 |
| 代价生效 | 胜利要扣血 | 每次大赢支付情感、健康或关系的代价 | 永远无损胜利 |
| 魅力自证 | 好感要靠事件攒 | 用守护、担当、细节赢角色好感 | 旁白宣布人见人爱 |
| 缺口可成长 | 缺口是弧光的料 | 缺口的弥补过程就是成长线本身 | 缺口天生不变 |
| 输要有戏 | 败仗也好看 | 安排一场完败，对手赢在谋略 | 主角败于低级失误 |

- **缺口使用规则**：软肋每卷至少被现实敲打一次；盲区至少导致一次失败；对手每利用一次软肋，主角就要加一道防或付一份账——缺口由此变成剧情引擎
- **缺口出身要早**：软肋在前期日常戏里自然露面，不能等对手要用才空降
- 结局缺口不必填满，保留一点不完美收束，留白也是余味

## 配角与反派塑造（避免脸谱化）

配角和反派是小说世界的重要组成部分，脸谱化的配角和反派会严重降低小说的质感。

### 反派塑造三原则

1. **动机合理化**：每个有名有姓的反派必须有合理的行为动机（利益、信仰、仇恨、恐惧、守护），不能为了作恶而作恶。反派的决策必须符合其身份和情报，不能突然降智。
2. **能力特色化**：不同反派的战斗方式、能力类型、行为模式必须有区分度（速度型、力量型、诡计型、控场型、辅助型），不能全部是"举着武器冲过来"。
3. **失败有代价**：主角击败反派必须付出实际代价（受伤、消耗资源、暴露实力、关系裂痕），不能轻松秒杀。越级战斗必须有规则内依据（智取/借势/代价），对手不许突然降智。

### 反派的立体层次

| 层次 | 内容 | 示例 |
|------|------|------|
| 表层 | 反派展示给外界的形象 | 残忍、嚣张、冷酷 |
| 中层 | 反派的行为动机和逻辑 | 为了救女儿、为了复仇、为了信仰 |
| 深层 | 反派的核心恐惧和渴望 | 害怕被遗忘、渴望被认可、恐惧失去 |

- **反派不能只有表层**：只有"残忍嚣张"的反派是纸片人，必须有中层的动机和深层的恐惧渴望，才能让反派立体。
- **反派的动机要能被读者理解**：不是认同，而是理解——"如果我是他，我可能也会这么做"。能被理解的反派才是好反派。
- **反派的失败要有悲剧感**：好的反派被击败时，读者会感到一丝惋惜，而不是"终于死了"的解脱。

### 配角塑造原则

- **配角不能是工具人**：长辈、执事、同门、路人各有立场和性格，严师有苦衷，反派同门有靠山，路人有自己的小算盘。
- **每个有名字的配角至少有 1 个独立于主线的个人目标或特征**：不是"帮助主角"，而是"他自己想要什么"。
- **配角的行为必须符合其身份和利益**：宗门长老优先考虑宗门利益，商人优先考虑利润，杀手优先考虑完成任务，不能为了配合主角而做出不符合身份的行为。
- **配角的出场要有功能**：每个配角出场时必须至少完成一项功能（推进剧情、揭示信息、制造冲突、塑造主角），不能"只是存在"。

## 配角功能类型库：一个配角至少扛一个功能

每个配角绑定单一功能标签，同屏功能不重复，重要功能位不长期空缺（空缺会让主角显得万能）：

| 功能位 | 原理 | 应该怎么写 | 坏写法 |
|--------|------|-----------|--------|
| 引路人 | 成长需要教学出口 | 师父前辈承担体系讲解与招式示范 | 主角无师自通全靠悟 |
| 对照组 | 强弱需要参照物 | 同辈天才标定主角每一步超越的含金量 | 对照组永远弱一档 |
| 镜子人物 | 选择需要映照 | 与主角同起点但不同选择的角色，结局互为答案 | 镜子人物与主角雷同 |
| 气氛组 | 节奏需要松弛 | 吐槽担当承担日常调剂与规则解说 | 全员严肃无喘息 |
| 资源位 | 主线需要供货 | 情报贩子、后勤担当供应信息与物资 | 资源凭空掉落 |
| 变数位 | 剧情需要波澜 | 立场摇摆者承担背叛或反正的反转 | 反转毫无预兆 |

- **功能位也是成长位**：引路人会退位、对照组会反超、镜子人物终局对答，功能随剧情演进，配置表每卷更新一次
- 变数位反转前至少 2 次行为铺垫；结局每个功能位给归宿并对照人物表销号（去向与功能一致），功能位只进不出是配置闭环的一半

## 配角人设防崩伏笔：行为与设定互为证据

给核心配角立一条可核对的行为准则，用日常细节提前铺垫关键抉择，防止"剧情需要变脸"：

- **锚定四件套**：① 一句原则定底线——给核心配角一句话原则，关键戏按原则行动，原则要可证伪、写进台词让读者背得出来；② 抉择预演——重大抉择前先给一次同型小选择铺垫；③ 弱点绑定——弱点要参与关键决策；④ 去向交代——重要配角给出场与落幕，落幕配回响
- **台词指纹**：口头禅、句式、称呼固定成每人一套说话习惯，众人不能一个腔调
- **一致性自检**：每个重要配角的高光或黑化时刻，回看其前史必须能找到至少两处行为伏笔——一处在前三分之一立性格（远证性格），一处在当下不久之前证动机（近证动机）；黑化另加一条：背叛的收益要在前文展示过，读者回看时能算出这笔账
- 崩坏高发位在反转：反转前补一处动机闪回，比事后用一章解释省力得多
- 禁止重要配角凭空蒸发；禁止用旁白宣布配角性格，性格要行为自证

## 角色心态转变的铺垫要求

角色的心态转变（尤其是主角的重大转变）必须有足够的铺垫，不能一句话就完成。

### 心态转变的三阶段

1. **触发阶段**：具体的事件或信息打破了角色原有的认知平衡（亲眼看到重要的人受伤、被逼迫到绝境、发现信仰的真相）。
2. **挣扎阶段**：角色在原有认知和新认知之间反复权衡，两种选择都有代价，角色的行为出现犹豫和矛盾。
3. **完成阶段**：角色做出选择，并且这个选择必须有具体的行动伴随（不只是"我想通了"，而是"我拿起了剑"）。

### 心态转变的篇幅要求

- **重大转变至少占用 1 段具体的心理活动或行为犹豫**，不能用"他深吸一口气，做出了决定"一句话带过。
- **转变前后的行为必须有可观察的变化**：转变前主角遇到危险第一反应是逃跑，转变后第一反应是面对；这种行为变化是心态转变的证据。
- **转变不能是永久性的**：重大心态转变后，角色在后续剧情中仍可能出现反复和动摇，这才是真实的人性。完全转变后再也不动摇的角色是纸片人。

### 常见错误

- ❌ 没有触发事件，角色无缘无故就变了
- ❌ 触发事件后立刻完成转变，没有挣扎过程
- ❌ 只有内心独白的"我想通了"，没有具体的行动伴随
- ❌ 转变后角色的行为没有任何变化，心态转变成了空话

## 人物关系设计

### 关系类型

| 关系 | 戏剧潜力 | 应用 |
|-----|---------|-----|
| 亦敌亦友 | 高 | 悬疑、动作 |
| 禁忌之爱 | 高 | 言情、悲剧 |
| 师徒关系 | 中 | 成长故事 |
| 兄弟竞争 | 中 | 家庭剧 |
| 陌生人联盟 | 中 | 冒险、悬疑 |

### 关系动态变化

**好的关系会随故事发展：**
```text
第一章：陌生人
第三章：不情愿的盟友
第五章：建立信任
第七章：背叛/考验
终章：真正的友谊（或决裂）
```

### 关系揭示

**逐步揭示关系深度：**
- 表层：表面互动
- 中层：共同经历
- 深层：真实感受/秘密

## 人物一致性检查

角色行为必须符合已建立的性格。

**检查问题：**
- 这件事符合他的核心价值观吗？
- 以他的背景，会有这样的反应吗？
- 他的恐惧会如何影响这个决定？
- 他的缺陷会导致他犯什么错？

**例外处理：**
- 如果角色"不符合性格"行事，必须有原因
- 解释应该在相同/下一章提供
- 可以是成长的标志（角色克服缺陷）

## 人物出场设计

### 首次出场原则

**有效的出场方式：**
- **行动中** - 展示能力或性格
- **冲突中** - 立即建立关系/对立
- **误解中** - 建立悬念

**避免：**
- 镜子自照描写外貌
- 姓名+年龄+职业的简历式介绍
- 无意义的日常活动

### 出场示例对比

| 无效出场 | 有效出场 |
|---------|---------|
| 李明，28岁，是一名侦探。他走进办公室。| 李明跨过警戒线，警官试图拦住他。"市刑警队，李明。"他亮出证件，径直走向尸体。|
| 美丽的女孩坐在窗边，她叫小红。| 她已经三天没睡了，咖啡杯里的液体在颤抖。当门铃响起时，她几乎把杯子摔在地上。|
