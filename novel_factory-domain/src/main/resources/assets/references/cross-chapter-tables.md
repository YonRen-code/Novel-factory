# 跨章一致性四表

长篇小说最容易翻车的地方不是单章写得好不好，是跨章前后不一致。把"一致性"从一次性的检查清单，升级成四张**持续维护的台账**：写好每一章前先看表、写完后更新表。与 consistency.md 分工：consistency.md 是检查清单（查什么），本文是台账机制（怎么持续记、怎么防漂移）。

## 一、道具链表

每个关键物件一张表，记录它每一章的位置/状态变化：

```
## 道具链 · 青玉簪
| 章 | 位置/状态 | 变化 |
|---|---|---|
| 19 | 女主发髻（家中带出） | 首次出现 |
| 28 | 女主发髻 | 男主所赠、贴身携带 |
| 37 | 异国巷道 | 被人碰断、掉在水沟 |
| 38 | 男主内袋 | 只剩半截残身 |
| 39 | 女主发髻 | 归还时已换新 |
```

规则：**写新章前先查表**，确认物件当前在哪、什么状态；**写完后更新表**。关键物件是"剧情说了算"的东西——定情信物、兵刃、信物、密卷，一律建表。

## 二、时间锚表

每章开头记一个时间戳，章间算跨度：

```
| 章 | 时间锚 | 距上一章 |
|---|---|---|
| 28 | 正月十八下午四点 | — |
| 29 | 正月十八夜九点零二分 | +5 小时 |
| 30 | 正月十八夜九点三十五分 | +33 分钟 |
| 31 | 正月十八夜十点前后 | +25 分钟 |
| 32 | 正月十八夜十点零七分 | +几分钟 |
```

规则：**跨天/跨月的章之间必须算清几周几个月**，防止"钩子说两个月后、正文算出来五周"这种读者一数就穿帮的错。时间跨度是强校验项（影响剧情因果与人物状态恢复）。

## 三、术语一致性表

同一个东西全书必须用同一个名字。改任何一处，全文对齐：

```
| 概念 | 统一叫法 | 禁用别名 |
|---|---|---|
| 关键文档 | "父亲当年灭门那份旧档复印件" | "前世被查封笔录复印件"（歧义） |
| 关键公章 | "歪半格的那枚朱印" | "那枚章" / "旧朱印" |
| 配角护身符 | "桃木符" | "小木牌" / "护身符" |
```

规则：术语名**宁长勿歧**——宁可啰嗦，不因缩写产生歧义。同一概念被换叫法 = 一致性破坏，读者会以为出现了新东西。

## 四、关键数字表

年龄、年份、件数、金额、比分——最容易前后不符的类别：

```
| 项 | 数值 | 出现章 |
|---|---|---|
| 主角灭门时年龄 | 8 岁 | 19/30/31 |
| 主角前世死亡年龄 | 28 岁 | 1/29/30/32 |
| 灭门年份 | 2000 冬 | 19/30/31 |
| 对决总比分 | 5 胜 2 平 | 33/34/35 |
| 反派刑期 | 有期徒刑 20 年 | 39 |
```

规则：数字项**必须完全一致**，写新章引用时回表核对；涉及结算的总分/金额/年限，写前先算一遍再落字。

## 五、钩子区 vs 正文核对

钩子承诺的东西正文必须兑现——这是"章末悬念"质量的关键：

最常冲突的四类（实战高频）：
- **比分**：钩子写"五胜两平"，正文算出来四胜两平加第七局
- **时间线**：钩子写"两个月后"，正文算出来五周
- **道具细节**：钩子写"推门进拍卖行"，正文是"推门进旧画廊"
- **罪名/清单项**：钩子列了三条，正文只兑现两条

核对方法（每章发布/定稿前）：
1. 把钩子段的关键名词、数字、时间、事件列出来
2. grep 正文逐项核对是否出现
3. 数字项必须完全一致（比分/时间跨度/金额/件数）
4. 名词项要统一叫法

## 可测量指标：破折号密度

"风格"是主观判断，但破折号密度可以量化，是稳定性最高的一致性/风格指标：

- 正文每章 ≤ 7 个"——"，读起来不碎
- > 10 个：明显"破折号滥用"
- < 3 个：过于平实，可能缺气口

**这个指标比"句子通不顺"稳得多**，可直接脚本统计，不用人工数。修订时特别注意——手抖加破折号、复制粘贴带入 ASCII 引号，每次改完都要重跑机械扫描。

## 自检清单（每章写完/定稿前）

- [ ] 本章出现的每个关键物件，道具链表已更新？
- [ ] 本章时间锚已记录，跨度与上章能对上？
- [ ] 本章用到的概念叫法，与术语表一致（无新别名）？
- [ ] 年龄/年份/比分/金额，与关键数字表一致？
- [ ] 钩子区的数字、时间、道具、清单项，正文全部兑现？
- [ ] 破折号密度 ≤ 7？（修正版必须重跑一次扫描）
