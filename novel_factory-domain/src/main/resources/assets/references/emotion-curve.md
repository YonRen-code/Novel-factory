# 情绪曲线与爽点节奏

设计章内与跨章的情绪波动：爽点/虐点/燃点的配方、密度与间隔，让读者持续产生"想看下去"的期待感。

## 核心原理：期待感是一切的锚

剧情、节奏、情绪技巧的最终目的都是**建立并兑现期待感**。读者追读不是因为"发生了什么"，而是因为"预感到即将发生什么"。

期待感的三种来源：
1. **目标预告** - 主角声明了目标（"三年内我要踏进内门"），读者等着看他做到
2. **承诺兑现** - 埋下的冲突/伏笔即将引爆，读者等着看爆点
3. **信息差** - 读者知道主角不知道的事（或反之），等着看真相揭开的冲击

**期待三要素**（任何承诺必须三样齐全，缺一样期待就不成立）：
- **画面化目标** - 把承诺写成可想象的画面：站上某座演武台、拿回某块牌位，而不是"变强"两个空词
- **有名有姓的障碍** - 谁或什么在拦，拦路者有名有姓有权势，障碍才产生张力
- **明确期限** - 时间节点或事件节点：明年今日、宗门大比前，期限才有紧迫感

**记账提醒**：期待会随时间衰减，每 3-5 章借对话或画面重提主承诺 1 次；全书同时挂的期待线不超过三条。

每卷、每弧、每章开工前先回答：本章让读者期待什么？兑现了哪个此前的期待？

## 波浪式情绪曲线

情绪必须波浪式推进，不能一根直线：

```
小不爽 → 小爽 → 小不爽 → 小爽 → 大不爽 → 大爽
```

- **压抑段占 20%-30%**：主角受挫、被轻视、危机逼近。压抑太短，爽点没分量；压抑太长（连续 3 章以上纯憋屈），读者弃书
- **释放段紧跟压抑**：大不爽之后必须接大爽，且爽的幅度 ≥ 压抑的幅度
- **禁止从头爽到尾**：没有压抑的爽是麻药，三章后读者免疫

### 峰谷错落模型（情绪记录法）

- 全书情绪不是平均用力，而是峰谷错落：**峰后必有谷，谷中必埋下一个峰的引线**，峰值逐卷递增
- 自查用情绪记录法：每章标注 1-10 的情绪值画成折线，**连续四章低于 5 或连续三章高于 8** 就调整大纲
- **峰谷交替**：每个高潮后安排 1-3 章低谷缓冲，把情绪值从 9 压回 4
- **谷中埋峰**：低谷段负责蓄力不是休息，埋入下一峰的引线（仇敌现身、宝物线索、误会种下）
- **峰值递增**：每卷情绪峰值高于上一卷（小比、夺宝、灭门、弑神逐级抬升），连续两卷峰高持平即退步
- **转折有坡**：情绪切换用半章到一章过渡（悲伤章里夹回味，燃章前先压抑），禁止情绪急转弯
- **多线错峰**：感情线在低谷时主线爬峰，配角线为主角的谷段供小峰；所有线不得同涨同跌
- **谷限长度**：连续低谷不超过 5 章，且每章必须推进至少一条线

## 爽点七大来源

爽点是读者欲望的及时兑现。"先立欲再兑现"是铁律：**没立欲直接爽，读者无感**。一本主爽点不超过三种，其余做调剂；同一章只用一种主爽点，混用互相稀释。

| 来源 | 欲望 | 应该怎么写 | 坏写法 |
|------|------|-----------|--------|
| 获得 | 占有的快乐 | 先借旁人之口或竞价展示宝物价值，再让主角得到 | 平白无故掉宝贝 |
| 变强 | 成长的快感 | 每次升级配 1 次实力展示或旧对手的反应 | 只报数值不展示 |
| 认可 | 被看见被尊重 | 先低估后认可，认可当众化且出自先前贬低者之口 | 认可来得无缘无故 |
| 复仇 | 正义被执行 | 仇恨先记账，回收有仪式感且当众完成 | 仇恨随写随忘 |
| 翻盘 | 以弱胜强 | 先亮明弱势与赌注，再借底牌逆风翻盘 | 对手降智送胜利 |
| 解谜 | 好奇心兑现 | 线索提前公平给出，揭晓时读者能回想起来 | 答案凭空冒出 |
| 情感 | 关系推进 | 关系升温必须由共同事件推动，每次推进一档 | 感情无事件硬升温 |

## 欲扬先抑循环

抑扬循环是爽点的发动机，**立欲 → 受挫 → 释放**三步缺一不可，另加进度提示与对等偿还保障长线。

| 支点 | 原理 | 应该怎么写 | 坏写法 |
|------|------|-----------|--------|
| 立欲 | 欲望是压抑的前提 | 先给主角明确的想要：参赛资格、宝物、尊严，写进台词或行动 | 主角无欲无求被欺负 |
| 受挫 | 障碍产生张力 | 让欲望被具体的人、规矩或时限拦住，拦路者有名字 | 为虐而虐 |
| 释放 | 释放要超出预期 | 主角用底牌跨过障碍，当众兑现且超出预期一档 | 求人代劳解决问题 |
| 进度提示 | 长压抑需要可感知的进度 | 跨卷压抑期每 3-5 章给 1 次进度（账本记一笔、名单划掉一个名字） | 压抑期原地打转 |
| 对等偿还 | 释放量与压抑量对等才有力度 | 压抑期立下的每笔账在释放段逐条偿还，至少加倍奉还 | 释放只还零头 |

**压抑时长红线**：单轮压抑不超过 2-3 章；跨卷压抑必须每 3-5 章给一次小甜头或进度提示，二者必居其一。释放当章章末再埋一笔新账，下一轮循环自动开张。每轮循环节奏不得完全相同（读者会预判疲劳）。

## 期待感管理：建立、叠加、兑现

### 期待建立（给一张能兑现的支票）

- **画面化**：承诺写成可想象的画面（站上某座演武台、拿回某块牌位）
- **配障碍**：明确是谁在拦，拦路者有名有姓有权势
- **给期限**：加时间或事件节点（明年今日、宗门大比前）
- **当众承诺**：让配角或对手当众说出主角的目标，形成公证人
- **里程碑拆解**：长承诺拆成 3-5 个可见里程碑，达成一个亮一个；避免只在结局一次性兑现
- **公开兑现**：阶段性兑现要公开化、仪式化，最好当着立承诺的对头兑现；私下悄悄兑现等于没兑现

### 期待叠加（目标套娃逐层加码）

- **套娃结构**：小目标是中目标的台阶，中目标通向大目标，逐层咬合，禁止目标平替（旧目标完成后换不相干新目标，期待断线，是中期流失高发点）
- **完成即升级**：小目标达成当章就暴露更大的门槛，入口即钩子，期待不隔夜
- **进度条**：用名次、层级、地图标明当前位置（外门第一、内门第十七）
- **加码可见**：新目标至少两项升级——对手更强、赌注更大、观众更多
- **余波继承**：新目标使用旧目标收获当台阶（名次、信物、人脉）
- **长线供电**：大目标每 5-8 章借他人之口或传闻提 1 次，防断电
- 临结局前 30 章内只剩 1 层目标且每章有进度，禁止临结局突然加层

### 期待兑现（拖到极限但不越线）

- **极限前踩点**：短线承诺三章内兑现，长线承诺卷末兑现；当章立当章还 = 没有等待就没有张力
- **临门抬价**：兑现当章先给一次变数、羞辱或加码，落差更大
- **断在兑现前**：兑现动作放在下一章开头第一场，在兑现前一拍断章
- **足额兑付**：兑现规格不低于承诺，最好超出一档；偷工减料 = 信任清零
- **台账排期**：每笔承诺登记立账章数与预计兑现章数；超十章的线兑现前一章先提醒；分批清账——一卷清掉六七成承诺，留两三笔跨卷线过卷，禁止同批全清后无线可吊

## 五类情绪点的配方

### 爽点（征服感）

| 配方 | 结构 |
|------|------|
| 打脸 | 被轻视 → 展示实力 → 围观者态度反转 |
| 越级挑战 | 实力差距明示 → 借助巧思/金手指 → 险胜 |
| 身份揭露 | 被误解/被看扁 → 真实身份或靠山揭晓 → 前倨后恭 |
| 装备/收获 | 苦寻不得 → 机缘到手 → 立刻用上 |

### 虐点（心疼感）

铺垫情绪 → 引爆情绪 → 宣泄释放。虐之前必须先给糖（先让读者爱上这个角色），虐之后必须给出口（释放或补偿），否则只有憋屈没有张力。

### 燃点（热血感）

绝境 → 不退 → 爆发。燃点需要"明知不可为而为之"的主动性，主角是被逼到墙角后主动迎上去，不是被动挨打。

### 泪点（共情感）

靠具体的小细节（一碗面、一句口头禅、一件旧物）承载感情，不靠直白的哭喊。死亡/离别前先写日常，日常越平静冲击越大。

### 甜点（心动感）

见 [style-references](genres/romance/style-references.md) 与 dialogue-writing 的潜台词章节。甜点靠克制：写动作细节，不写"心动"二字。

## 高频爽点四流程

### 打脸四步闭环

**挑衅 → 压制（情绪负债）→ 蓄力（亮牌不翻）→ 爆发（当众清账）**，流程外两条外置规则：观众在场 + 规模递进。

- 压制：主角吃亏或隐忍 2 章左右，代价具体可见，禁止跳过压制直接爆发
- 蓄力：暗示主角已有翻盘手段但按住不动
- 爆发：当众翻盘，反派付出的比索取的多
- 观众在场：爆发前安排至少一名在场观众，最好是此前看轻主角的人；胜利发生在密室 = 哑炮
- 规模递进：每次打脸的对手层级、场合规格、赌注大小都高于上一次
- 打脸必须真实改变主角处境（有后果），同一反派打脸不超过两次

### 升级可视化

- **升级必演示**：升级后立刻用一件具体事展示新能力，杜绝只报数字不给画面
- **参照物锚定**：用固定参照物（某层次的人、某类妖兽）衡量实力，参照物不得随剧情随意变动
- **升级有代价**：升级需要资源、机缘或冒险去换，禁止睡觉涨级
- **战果自洽**：升级后能稳定打赢此前打不过的那一档对手；禁止升三级还打不过旧对手
- **频率配比**：小升级 2-3 章一次且演示从简，大升级每卷至多一次；升级频率不得超过演示能力（数值通胀）

### 夺宝流水线

**先验价 → 设门槛 → 险中得 → 到手即用**，外加怀璧其罪把收获变钩子。

- 价值前置：获得前让他人争抢、展示宝物的威力（三板斧验价：别人抢破头/行家惊呼来历/老买家开价，任选其二）
- 有门槛：设置竞夺者、机关或代价，最好拿走一件旧物交换；严禁顺手一捡
- 到手即用：当章或次章让宝物发挥一次可见作用，禁止进仓库吃灰
- 怀璧其罪：得宝后引来新势力觊觎，把一次收获转成下一场冲突；一章不得连得数宝

### 高光认可

**铺垫低估 → 当众验证 → 反应分层 → 地位兑现**，低估越狠认可越爽。

- 在场者基于合理判断轻视主角（禁止集体降智制造低估）
- 考核、比武、拍卖等有观众的场合证明，禁止私下自证
- 反应分层递进：质疑 → 震惊 → 敬畏，禁止全员一夜转粉
- 认可要兑换成实际待遇（资源、人脉、话语权），口头夸赞留不住爽感
- 权威压轴：场内小人物先震惊，掌门长老级的定评压到卷末；每个新环境重置低估再走验证流程

## 复仇线倒计时

复仇期待靠账目管理：**早立账、账目可见、分步还账、仪式化兑现**。

- 早立账：仇恨事件前三章内发生且代价惨重（具体到亲人与家园），禁止复仇动机后置补写
- 记账可见：仇人名单明确，每笔仇有场景有证据；禁止笼统记在某个势力头上
- 分步还账：先清爪牙再动核心，每卷还一笔（第 10 章划掉告密者、第 20 章划掉执刀人）
- 仪式化兑现：当众清算、真相揭穿、仇人当面认账；禁止偷偷杀掉或死于意外
- 进度通电：每卷让主角向目标靠近一格，或让仇人阵营露一次面；禁止复仇线断线超一卷
- 仇人保鲜：每卷至少插一场仇人阵营作恶或得意的戏；禁止仇人三年不出场
- 清算完毕的空虚感要给出口（转向守护与新生），不能停在杀完就走

## 密度与间隔

| 层级 | 频率 | 说明 |
|------|------|------|
| 微爽点 | 每章至少 1 个 | 小胜利、小机缘、一句解气的台词 |
| 小高潮 | 每 3-5 章 | 一次打脸/突破/身份小揭露 |
| 弧高潮 | 每弧（8-20 章）1 个 | 该弧核心冲突的总爆发 |
| 卷高潮 | 每卷 1 个 | 改变格局的大事件 |

**三小爽一大爆节拍器**：小爽 3-5 章一次（兑现须推进主线一小格）、中爆约 10 章一次（规格明显高于小爽一档）、大爆绑定卷末（多线汇聚）。开卷前列节拍表标注预计章号与兑现内容，写作偏差控制在两章以内；大爆前 2-3 章压低兑现密度、抬高危机蓄压，禁止大爆前连发同级小爽泄压；新卷第一章就落一拍小爽或强钩。

**爽感递增法则**（同类爽点必须一次比一次重，规格持平就是退步）：
- 对手层级越换越高（高 1-2 档），赌注从脸面到利益到性命再到珍视之人，场面规模越打越大，翻盘代价越赢越险
- 给每类爽点建历史规格表，新事件动笔前先对照，规格不低于上一次；开局用最低档留足上升空间
- 跳档后允许两三场平级小爽消化战果；结局规格不得低于此前任意高潮

**同类爽点疲劳处理**（同型连用必脱敏，脱敏根源是结构重复）：
- 间隔拉开：同类大爽点间隔一卷以上，中间穿插他型爽点
- 形式变奏：同是翻盘，换成智取、借力、反间，结构必须真的变化（只换对手名字 = 读者识破）
- 维度轮换：获得型疲劳后切情感型或解谜型；全书爽点种类不少于三种
- 规格升级：对手、赌注、场合至少一项升 1-2 档
- 疲劳信号：章评出现"套路/就这/水"关键词、同类情节热度环比下滑，即触发轮换
- 执行者换手：同类爽点偶尔交给配角执行，主角受益或善后

**禁忌间隔**：同类型爽点相邻两次之间至少隔 2 章，且幅度要有变化——连续三次"打脸围观"读者必然疲劳。

## 虐与爽配比

虐是爽感的投资：**单次虐要短、要有意义、之后必有等额或超额补偿**。

| 支点 | 应该怎么写 | 坏写法 |
|------|-----------|--------|
| 虐短爽长 | 单次虐不超过 2-3 章，补偿篇幅不少于虐（最好超出一截） | 虐五章爽半章 |
| 虐有目的 | 每个虐点的亏要换来成长、线索或情感深化（三选一） | 为虐而虐 |
| 补偿对等 | 受了多少委屈就让对方付出多少代价，最好当众偿还 | 委屈不了了之 |
| 底线护住 | 核心亲人与人格尊严可以险被夺但不被毁 | 无底线虐待主角 |
| 回收限时 | 虐点在 5-10 章内转化为翻盘点，把委屈变成打脸弹药 | 虐完石沉大海 |
| 出口预告 | 虐戏当章让主角立誓或定下反击计划，读者知道账会被还 | 主角默默忍受不表态 |

- **禁止用误会制造虐**：一句台词就能解开的矛盾读者最反感
- 每个虐点登记预计回收章数；结局不再新开虐点，只做幸福兑现，把每笔补偿逐项点名兑现

## 慢热题材的替代期待源

慢热文必须建立替代期待源（关系推进、谜团、生活流钩子轮换供电），**慢而不空**：

- **微推进**：每章人物关系或信息推进一小格，禁止连续五章零推进
- **关系钩**：每卷完成一次关系质变的靠近
- **谜团供电**：主谜团分层放糖，每卷给一块拼图，禁止谜团十年不动
- **生活流锚点**：用固定场景、食物、仪式感做连载锚
- **甜点定投**：每卷两三次小满足（关系升温、小谜揭开、小愿望达成）
- 慢热不等于开篇冷场：前三章仍需事件开场、立主钩并给期限；禁止慢热文突然转向快节奏爽文（读者按原契约进来）

## 悬念与期待感的配合

悬念问"那是什么"，期待问"他会怎样"，**分工明确、错峰释放**：

| 支点 | 应该怎么写 | 坏写法 |
|------|-----------|--------|
| 分工明确 | 悬念线管谜底，期待线管兑现 | 一条线既藏谜底又许诺兑现 |
| 读者已知 | 悬念靠角色未知维持：读者知道炸弹在哪，角色不知道 | 对读者也隐瞒已知信息（假悬念） |
| 双线咬合 | 揭一层悬念就推进一格期待 | 两线各走各的 |
| 错峰释放 | 悬念与期待分章兑现 | 同章双爆互相踩 |
| 配置公式 | 全书一条主悬念 + 一条主期待，副线各不超过两条 | 主副悬念期待挂满一屏 |
| 追问台账 | 每卷末列出读者此刻最想问的三件事，下卷逐一作答 | 不知道读者在等什么 |

开篇挂牌：第一章挂牌主期待，第三章前挂牌主悬念；禁止只挂一条线；悬念揭底后必须有新悬念接棒。

## 打脸场观众预设

打脸的爽感一半来自观众，观众席是打脸戏的前置工程：**入场 → 断言 → 见证 → 传播**，前两步发生在开打之前。

- **提前入场**：打脸前一两章让关键观众自然到场，禁止开打时人物凭空出现
- **带前史**：优先安排看轻过主角的人在场，见证重量来自关系
- **反应分层**：从质疑到震惊到改口分层呈现，禁止全场整齐划一惊叹
- **断言回旋**：打脸前让观众说出断言式狠话（"他若能赢我吞匾"），翻盘后原话奉还
- **传播出去**：打脸结果被旁观者带出场外发酵，传播版本至少两个且细节走样
- **配置配比**：核心观众 1-3 名（有恩怨前史）、氛围观众若干、权威观众一名；观众是背景板不是主角

## 配角高光章

配角高光是限时授权，红利必须流向主线与主角：

- **一章为限**：配角高光单章完成，至多两章，禁止连占五章喧宾夺主
- **主角在场**：配角的爆发服务于主角目标，主角在场或远程受益
- **挂钩主线**：高光同时推进主线信息或资源，禁止纯缅怀式支线
- **高光有铺垫**：高光前该配角有至少两次铺垫出场，禁止临时起意捧配角
- **缺位补偿**：主角缺席时用主角视角的牵挂或章末回归钩住主线
- **高光定价**：配角高光付可见代价（重伤、牺牲），产出归入主线或主角名下
- 配角不能在主角关键战中抢走最后一击；主角的关键一击必须留在一人身上；高光配角两卷内给交代，禁止高光后立刻写死

## 感情线节奏控制

感情线用推拉循环推进：**靠近 → 小波折 → 再靠近**，误会全书限额一次。

- **事件推关系**：每次靠近或破裂绑定具体事件（共历生死、并肩任务、当众维护），禁止"相处久了自然在一起"
- **推拉有度**：一次后退不超过两章就给缓和信号，靠近期拉长到 3-5 章；后退要短于靠近
- **误会限额**：同一对 CP 全书核心误会不超过一次，且 3-5 章内解明；禁止误会连用续命、用误会拖延超三章
- **主从分明**：感情节点挂在主线事件上（夺宝中互救、大比后表白），禁止连占五章挤掉主线
- **第三者限额**：情敌或阻碍者只做催化剂，推动主角认清心意后一个阶段内退场
- **阶段目标**：按相识、并肩、心动、表白、定情五档推进，每卷至少进一档；结局前 5 章内关系终点落地，禁止开放式暧昧或临时换 CP
- **双高光**：表白或定情级节点安排在主线高潮战后 1 章内，双方各留一次高光选择，禁止只靠一方单向付出

## 危机压迫感营造

纸面危机没有威胁——压迫感公式：**具体期限 × 递减资源 × 可见代价**，三项缺一，危机就只剩形容词：

- **上倒计时**：危机带明确期限（三天内解蛊、毒发只剩一炷香）；无限期的威胁是背景音
- **资源递减**：灵石、丹药、人手、时间随剧情真实减少，每章盘点存量；仓库见底的那章才是追订高峰
- **代价可见**：开局让配角或前人因同类危机真实死亡或致残立下先例——死不了人的世界吓不住人
- **压迫有层次**：压力逐级加码（外围哨探→封锁补给→核心决战），禁止开局顶格施压无牌可打
- **喘息配给**：高压不超过 3 章就给半章喘息，用喘息章盘点损失与计划；连续紧绷十章读者的神经先断
- **期限递进**：把大期限切成小节点（第一天失水源、第二天折一将、第三天决战），不要只在最后一天提
- **兑现纪律**：威胁喊了必须兑现，读者只信一次，狼来了之后压迫感永久报废
- 危机要威胁配角与世界而不只是主角：规则一视同仁，无消耗的冒险没有紧张感

## 章内情绪过山车

单章内部也要有波动，禁止一章一个情绪平板：

```
承接上章情绪（快）→ 波动/恶化（中）→ 本章爽点释放（快）→ 尾钩子（悬）
```

- 高密度段（战斗、对峙）用短句快节奏
- 释放后留一小段低密度（喘息、日常、温情），为下一轮压抑蓄势

## 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 连续 3 章以上纯压抑 | 弃书 | 插入微爽点或暗线进展 |
| 连续 3 章以上纯爽 | 免疫、无期待 | 主动埋新的压抑源 |
| 爽点无见证者 | 打脸无力 | 安排围观者/当事人态度反转 |
| 情绪点同类型复读 | 疲劳 | 爽/燃/甜轮换，参考 anti-ai-tone 模式化循环判据 |
| 章内无波动 | 平淡 | 压缩背景、增加一个转折 |
| 没立欲直接爽 | 作者爽读者无感 | 先立欲（画面化目标+障碍+期限）再兑现 |
| 兑现缩水 | 信任清零 | 兑现规格不低于承诺，最好超出一档 |
| 大爆前连发同级小爽 | 高潮泄压 | 大爆前 2-3 章压低兑现密度蓄压 |
| 高潮后立刻续高潮 | 阈值飙升麻木 | 中间插 1-3 章低谷缓冲并埋下个峰的引线 |

## 自查清单

- [ ] 本章读者的期待是什么？来自哪个此前埋的点？
- [ ] 本章有没有至少一个情绪释放点？
- [ ] 压抑段是否超过 2 章未释放？
- [ ] 最近的爽点是否和上一次同类型且同幅度（递增了没）？
- [ ] 大爽点是否有在场见证者与态度反转？
- [ ] 本章是否立了新欲（画面化目标+障碍+期限三要素齐全）？
- [ ] 是否兑现了此前的承诺？兑现规格是否足额甚至超出？
- [ ] 最近 5 章情绪值是否低于 5 或最近 3 章高于 8？
- [ ] 主承诺是否已超过 3-5 章未重提（需要供电）？
- [ ] 同类爽点是否已间隔一卷以上（需要变奏/换维度）？
