# 都市异能/觉醒 弧型参考

适用于都市异能、全民觉醒、超能力进化等"现实背景 + 个体超常"的长篇。与 genre-flow-tactics 的【都市异能】节配合：那边管爽点通道与雷区，这里管弧线骨架。每条弧的章数按卷长伸缩。

### 觉醒开局弧（5-10 章）

2-3 章觉醒事件（仪式/事故/契机，越日常越好） → 2-4 章能力的第一次失控与小用 → 1-2 章被体制/组织注意到

- 能力开局"看着弱"比"看着强"好写：弱能力靠用法翻盘，强能力要立刻背代价
- 觉醒必须改变主角的社会处境（被人另眼相待/被机构登记/被家人担忧），不许觉醒完生活照旧
- 第一次使用能力必须有目击者——秘密的重量从第一章就开始累积

### 等级攀升弧（10-20 章）

2-3 章新等级/新区域的信息差 → 4-8 章冲级过程（试炼/任务/排位，穿插人际） → 2-4 章晋级关键战 → 1-2 章新等级带来的社会位置变化

- 等级必须量化且公示（F-SSS / 一至九阶），读者随时知道主角站在哪一级
- 等级要绑定社会权益（执照、准入、法律地位）：升级不只是变强，是换一种活法
- 每次晋级安排一次"低等级反杀高等级"或"高等级碾压带来的窒息"，两种体验交替

### 能力组合/顿悟弧（6-12 章）

2 章瓶颈（能力单一被克制） → 3-5 章与他人配合或特殊经历触发新用法 → 1-2 章组合技成型 → 1 章用组合技解一个此前无解的局

- 新用法来自已有能力的重新组合，不凭空加新能力；每次组合要写清"为什么以前没想到"
- 克制主角的那个对手，他的能力逻辑要自洽，被翻盘时读者能回想起伏笔

### 换体系/换地图弧（10-20 章）

2-3 章旧体系天花板显现 → 3-6 章新世界/新规则入场，主角旧优势部分清零 → 4-8 章在新体系内重新爬升 → 1-2 竧新旧体系并轨，旧等级换算保留

- 换体系前必须让旧体系的故事讲完（旧对手清账、旧恩怨了结）
- 换算关系要保留：旧等级在新世界的对应写明，读者据此掂量主角斤两
- 换地图后第一个朋友/敌人，最好与旧地图有暗线勾连

### 身份暴露/体制冲突弧（8-15 章）

2-3 章秘密的口子撕开（一次瞒不住的救人/破坏） → 3-6 章体制的收编、监控与博弈 → 2-4 章主角在编制与自由之间的选择 → 1-2 章达成脆弱的共存

- 体制不是反派：它讲程序、有内部山头、办事慢，但确实是秩序
- 暴露的推手最好是主角自己的选择（救人/护短），不是对手查出来的
- 收编条件里必须有一条主角绝不能接受的，为后续冲突埋线

### 源头之谜弧（贯穿卷级）

每卷揭开一层能力的来历（觉醒原因/体系起源），每层答案带出更深的问号

- 来历线索碎片化埋设：一次化验单、一段影像、一个老人的口误
- 全书内只回答"能力怎么来的"，"为什么是主角"留到终局或全书完结
