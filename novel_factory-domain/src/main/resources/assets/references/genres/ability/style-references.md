# 都市异能/觉醒 风格参考

现实背景 + 个体超常的写法约束。异能文最大的坑是"能力展示轰炸"和"数值通胀"——能力的稀缺性就是爽感本身。本文件随题材包注入正文场景。

## 能力展示的节奏纪律

- 每 5 章**至多 2 章**出现能力展示时刻；相邻两次必须换用途（战斗/救人/生活/赚钱轮换），禁止连续两次都是打斗
- 展示只走半步：旁观者的反应停在"愣住、多看一眼、私下议论"，禁止当场惊呼"这不可能"并反复确认
- 同一个能力的新用法才值得写；已用过的老用法再展示必须换场景功能（上次救人、这次破案、下次赚钱）
- 能力冷却、消耗、副作用每卷至少真实生效 2 次：写能力的重量，读者才信能力的价值

## 等级与社会的绑定

- 等级体系必须量化公示（F-SSS / 一至九阶皆可），主角当前等级在任何章节都要可回答
- 等级挂钩社会规则：执照、保险、择业、婚恋、法律刑责——高等级的特权与义务都要写
- 越级挑战要有明确依据（克制关系/信息差/地利/道具），禁止纯意志力越级；每卷越级至多 1-2 次
- 换体系时旧等级换算必须保留（旧 S 级 = 新体系几阶），读者拿它掂量主角

## 战斗与日常的配比

- 战斗戏与日常戏约 2:3 交替；连续两场战斗之间必须垫人际或生活场面
- 战斗写"解法"不写"招式堆砌"：能力怎么用、为什么这么用、对手怎么应对，三步讲清
- 日常戏里能力只做辅助（修东西、找猫、赚外快），让读者看能力融进生活的质感

## 秘密与人际

- 主角能力的知情圈要管理：家人/挚友/组织/对手逐层知情，每次知情圈扩大都改变处境
- 对他人能力的态度写出现实感：围观者的敬畏、既得者的傲慢、落后者的酸——不全是恶意
- 反派动机优先从"等级社会的不公"里长出（被等级制度碾过的人、靠等级作恶的人），少用疯子反派
