# 奇幻风格补充参考

## 世界构建

- 魔法/力量体系必须有明确代价，不能出现"无限能量"
- 种族特征要在行动中自然展示，禁止百科式灌输
- 新设定首次出现时通过角色互动引出，不用旁白解释
- 力量层级差距可感：高一个境界强在哪，要能用具体表现说清（细节见 worldbuilding.md）

## 修炼与境界

- 突破必须占用章节篇幅：瓶颈困境 → 机缘/代价 → 过程 → 验证，禁止"坐下三天就突破了"
- 境界变化前对照记忆前缀的【主角境界锁定】，本章计划无突破事件则境界纹丝不动
- 修炼日常要推进暗线（心结、感悟、人际），不是打坐流水账
- 资源体系（灵石/丹药/功法）保持价值锚定，前后一致

## 战斗与能力描写

- 战斗重点是策略和代价，不是招式名称堆砌
- 能力上限在 world_rules 中已约定，严禁突破
- 受伤要有持续影响，不能"下一场景就好了"
- 战斗差异化：不同敌人的战斗写法不同（速度型、力量型、诡计型），参照 anti-ai-tone 防止"法宝反应公式化"
- 越级战斗必须有规则内依据（智取/借势/代价），对手不许突然降智

## 金手指运用

- 金手指能力边界尽早披露，读者能用它预判主角的可能性
- 每次动用金手指要有成本或限制（冷却、消耗、暴露风险）
- 关键翻盘只允许用已披露的金手指能力，禁止临场加新技能
- **金手指规则仅在存在时启用**：只有故事设定明确建立了金手指/系统，才要求后续持续发挥作用并每 3 章至少有 1 次使用或有意义提及；没有该设定时跳过本条，不得凭空添加外挂
- **系统提示频率控制**：系统流小说中，系统弹窗同一场景不超过 2 次；日常状态播报（如"经验+10""好感度+1"）直接删除，只在关键节点显示具体数字
- **金手指遗忘检查**：主角遇到困难时，必须先考虑是否可以用已建立的金手指解决，不能明明有金手指却完全想不到使用

## 宗门与势力互动

- 宗门由利益驱动：贡献点、地位、资源分配天然生成冲突
- 主角与势力关系要有演变轨迹（边缘→站稳→崭露头角→举足轻重）
- 长辈、执事、同门各有立场，不都是工具人：严师有苦衷，反派同门有靠山
- **反派必须有动机和逻辑**：每个有名有姓的反派必须有合理的行为动机（利益、信仰、仇恨、恐惧），不能为了作恶而作恶。反派的决策必须符合其身份和情报，不能突然降智
- **反派的能力要有特色**：不同反派的战斗方式、能力类型、行为模式必须有区分度（速度型、力量型、诡计型、控场型），不能全部是"举着武器冲过来"
- **反派的失败要有代价**：主角击败反派必须付出实际代价（受伤、消耗资源、暴露实力、关系裂痕），不能轻松秒杀。越级战斗必须有规则内依据（智取/借势/代价），对手不许突然降智
- **配角不能是工具人**：每个有名字的配角至少有 1 个独立于主线的个人目标或特征，不是"帮助主角"，而是"他自己想要什么"

## 氛围营造

- 通过五感描写建立异世界沉浸感
- 日常生活细节（货币、食物、交通）体现世界观
- 避免所有角色都说现代普通话，适当使用世界观内的表达方式
- 灵气、法宝、秘境的描写保持感官具体，忌"气息恐怖如斯"式的空洞渲染

## 常见陷阱

- 龙傲天：主角能力攀升要有合理代价和挫折
- 设定膨胀：每章最多引入一个新设定概念
- 语言穿越：避免现代网络用语出现在古典背景中
- 换图失忆：进入新地图（秘境/新域）时，旧积累要有转化路径，人脉名望不作废
