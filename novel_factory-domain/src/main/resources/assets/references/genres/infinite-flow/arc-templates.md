# 无限流/副本/规则怪谈 弧型参考

适用于无限流、规则怪谈、惊悚游戏、轮回副本类。核心方法论：**顶层规则先行，副本往下长**——先定主世界的总规则，再设计副本；每个副本是单元剧，主世界是连载骨架。与 genre-flow-tactics 的【无限流】节强绑定（七三开规则/首本学费/难度递增），那边管节奏铁律，这里管骨架。

### 入局弧（5-10 章）

2-3 章日常与异常（被拉入的契机，越日常越好） → 2-4 章主世界规则亮相（结算、交换、奖惩，一次讲清总规则） → 2-3 章首个副本入场前的人际初见

- 首个副本选规则清晰、读者熟悉度高的场景类型，让读者跟主角一起学规则——第一个副本是教学关，不是劝退关
- 主世界的总规则（怎么进来、怎么出去、代价是什么）在入局弧内必须交代完整，此后不许追加新总规则
- 主角付一次学费（首本按错规则亏一次），学费换来的是他对规则的理解深一层

### 单个副本弧（8-15 章/副本）

1-2 章入场与表层规则发放（七成明规则） → 4-8 章试探与减员（隐藏规则逐步现形，队伍内博弈） → 2-3 章真假规则的推理与破局 → 1-2 章结算与成长落袋

- 每个副本预告过的明规则必须全部回收（明规则不许是废纸），隐藏规则 2-3 条，靠错误与观察补全
- 副本之间题材、机制、胜负条件必须差异化（换地图=换规则形态，不是换个皮再跑一遍）
- 破局必须落在已交代的规则上；队伍至少减员或重创一次，全员生还的副本全卷至多一个

### 规则怪谈型副本专用结构

表层规则之间故意留矛盾（规则 A 与规则 B 冲突） → 玩家必须推理哪条被人动过手脚 → 真规则的证据埋在场景细节里

- 矛盾规则的证据给读者与主角同等机会：细节在明处，猜不到是能力问题不是信息不公
- 恐怖感来自"规则的未知执行者"，不来自血腥描写；氛围靠日常的细微错位

### 队伍/群像弧（穿插型）

3-6 个固定队友各有能力与私心 → 每个副本至少一人有个人线推进 → 主世界的队友关系是长线追读动力

- 队友的能力差异要构成互补（缺了谁这个副本都难过），抢功能的队友要么转型要么离队
- 队内背叛或隐瞒每卷至多一次，且事出有因（各自的委托/把柄）
- 新人入队即风险源：他的第一次失误要消耗全队

### 主线阴谋弧（卷级暗线）

主世界的运营方、轮回的真相、副本世界的来源——暗线每 2-3 个副本推进一小步，禁止百章不动

- 每次推进以实证落地（一件带出的道具、一段副本身的异常、一个"不该在场的玩家"）
- 主角在主世界的积累（兑换、人脉、权限）与副本内成长双轨并行，结算日是每卷的爽点锚
- 终局层允许留白：副本从哪来可以不答，"我们为什么被选中"要在中后期给出方向

### 主角成长双线弧（贯穿型）

副本内的生存能力（游戏理解、规则推理）与副本外的人上积累（兑换能力、身份、资源）双线并进；成长必须"花学费买来的"——每次死亡、每次减员都要折算成他下个副本的判断依据
