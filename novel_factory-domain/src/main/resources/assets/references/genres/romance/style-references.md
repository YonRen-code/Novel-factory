# 言情风格补充参考

## 情感递进

- 感情发展遵循"排斥→好奇→动摇→确认→考验→稳固"曲线
- 每章推进一个情感阶段，禁止跳跃式发展；每个阶段用具体事件支撑，不靠旁白宣布感情变化
- 心动瞬间要通过具体细节呈现，不用"心跳加速"等抽象描写
- 推拉节拍：吸引 → 抗拒 → 更大的吸引，一方先心动并改变互动模式，制造另一方的不确定感

## 心动瞬间的写法

- 不写"爱"字，用行为细节让读者自己感到心动：多看的一眼、顺手递伞、记得对方的忌口
- 互动模式的转变最有力：从针锋相对到下意识维护，读者从"变化"里读出感情
- 心动后的反常行为（话变少、绕路、心不在焉）比直接告白更有戏

## 甜虐配比

- 甜虐交替是节奏的艺术：全程甜会腻，全程虐会弃；虐之前先给糖，虐之后必须给出口
- 虐的三段式：铺垫情绪 → 引爆情绪 → 宣泄释放（和解/真相/补偿）
- 糖点密度：甜宠向每章至少一个糖点；虐恋向每弧至少一个糖点压舱
- 大虐（分手/决裂/牺牲）放在弧点位置，且必须有后续回收，不许为虐而虐

## 误会的设计

- 误会必须有**成立的信息差**：角色不知道的事要有合理原因（不在场、被蒙蔽、性格盲区），禁止靠降智维持误会
- 误会要有**解开的窗口压力**：一次错过要付出代价（他人插手、证据消失），拖延才有张力
- 误会存续期 ≤ 一个弧；解开误会本身就是重要爽点，值得用足笔墨
- 因误会破裂的关系，和解要伴随认知升级（理解了对方的处境），不能一句道歉了事

## 关系张力

- 核心 CP 之间必须有持续的阻力源（性格、身份、误会、外部）
- 阻力要合理且难以轻易解决，不能为虐而虐
- 配角感情线不能抢主线篇幅，每章配角互动不超过 20%
- 情敌/第三方要有真实魅力与合理动机，赢不过主角但也不能是纸片人

## 对话质量

- 暧昧期对话要有潜台词，角色说的和想的应该不一样
- 吵架/冲突场景双方都要有道理，不能一方全错
- 甜蜜场景要有克制，过度撒糖会降低读者感受
- CP 之间的对话要有专属模式（互怼、暗语、未说完的话），后期靠唤起这个模式制造情绪

## 常见陷阱

- 降智推剧情：不让角色为了制造误会而突然变笨
- 工具人配角：每个配角都应有自己的动机
- 人设崩塌：感情中的行为必须符合角色已建立的性格特征
- 男弱女强/强取豪夺等模式化关系：感情双方都要有独立目标与成长线
