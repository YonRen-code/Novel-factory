# 悬疑风格补充参考

## 线索布局

- 调查推进章优先新增或推进线索；过渡章不强制埋线，但必须改变人物判断、关系或调查方向
- 关键线索必须在揭晓前至少出现两次
- 线索首次出现要自然融入场景，不能刻意强调
- 三线交织埋设法：重要线索用「物件 + 对话 + 行为」多条铺陈，读者漏掉一条还有别的可抓
- 建立心理线索表：每条线索记录 埋设章 → 提及章 → 揭晓章，防挖不填（与伏笔账配合）

## 诡计与反转设计

- 核心诡计（谁做的/怎么做的/为什么）在动笔前就想透，倒着写：先定真相，再反推所有章节的呈现
- 反转强度取决于早期暗示的充分度：揭晓时读者应能回想起 ≥3 处伏笔，拍腿而不是茫然
- 叙述性诡计遵守"不说谎但可省略"：呈现的内容全部真实，只是隐去关键视角
- 每弧至多一次大反转，连续反转会让读者不再信任叙事

## 误导技法

- 红鲱鱼要有独立的合理性，不能事后看完全无意义
- 叙述性诡计需要严格遵守"不说谎但可以省略"原则
- 嫌疑人转移要有动机支撑，不能为了误导而误导
- 三种常见误导：视角误导（只展示部分所见）、节奏误导（用强事件掩盖弱线索）、情感误导（让读者讨厌/同情某人从而放走真凶）

## 节奏控制

- 紧张→舒缓→更紧张的波浪式节奏
- 信息释放要节制，每次只给读者"刚好不够"的信息量
- 章末必须有悬念钩子，禁止"平静收尾"
- 调查推进要有阶段产出：每章至少一个"排除/确认/新疑点"，禁止原地兜圈

## 氛围营造

- 恐惧来自具体感官细节（声音、气味、温度异常），不来自"阴森恐怖"的定性词
- 日常中的违和感最瘆人：熟悉环境里一个不该在的东西、一句不该知道的话
- 调查场景的压迫感用时间与空间营造：限期内、空楼里、深夜里

## 逻辑严密性

- 时间线必须可回溯验证（与记忆前缀的时间点对齐）
- 不在场证明、动机、手法三要素缺一不可
- 揭晓时读者应该能用已知线索自行推导出结论
- 侦探/主角的推演只能基于已呈现的线索，禁止开天眼破案（视角纪律）
- 真凶的行为全程要经得起复盘：他把"不在场"做圆了吗？他为何此刻动手？
