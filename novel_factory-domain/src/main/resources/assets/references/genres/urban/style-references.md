# 都市重生/年代现实 风格参考

无超自然体系的重生/年代文，质感来自"可信的时代 + 可信的人 + 克制的爽"。本文件随题材包注入正文场景，写作时对照执行；节奏打法见 genre-flow-tactics 的【重生先知】【年代文】两节。

## 认知落差的克制展示

重生者的"不寻常"是全书最大的资产，也是最容易写砸的资产。

- 每 5 章**至多 2 章**出现展示时刻；相邻两次必须换载体（动作暗示 / 旁人评价 / 专注偏好轮换），禁止连续两章用"微动作 + 旁人惊叹"组合
- 单次展示只走半步：主角做出动作即可，旁人的反应停在"多看一眼""嘀咕一句"，禁止当场点破或连续追问
- "不像孩子"这类评价全卷至多 2 次，且每次要换具体的观察角度（饭桌 / 生意 / 眼神，不重复）
- 早慧的主推进方式是"观察者跨章累积的疑心"：A 章起疑、D 章再起疑、G 章私下求证——不是每章发一次展示
- 被人问起时，主角要有符合年龄的掩饰动作（打岔、装傻、哭闹转移注意力），掩饰本身可以露拙

## 时代质感

- 金额必须可换算：工资、物价、票价写具体数（2002 年普通工人月薪约 800-1200 元，一碗馄饨 1-2 元），大额交易拆成"几张票子"
- 每卷至少 5 件年代实物（粮票/BP机/录像厅/搪瓷缸/28自行车），实物要参与剧情，不许当布景
- 严禁现代词穿帮：手机（当时是"小灵通/手机"要符合年份）、网络、微信、快递（当时是"邮寄/托运"）按年份查证后才能出场
- 对白带年代腔与地方口吻："单位上""票子""户口""顶职"，长辈说话带教训腔，邻里带打听腔
- 大事件写家常侧面：下岗写"厂里这家那个的传话"，股潮写"隔壁谁谁亏了三万"，不写社论

## 日常与爽点的配比

- 温情日常戏与搞钱/布局戏约 3:2 交替，连续两场爽点之间必须垫一场日常
- 日常戏不是过场：每场至少推进一条人际线（家人 / 邻里 / 青梅），或埋一个后文要用的物件/人情
- 家人反对与支持都要有具体的利益理由（棺材本、脸面、户口、厂里编制），不许纯情感化站队

## 数字的账目感

- 挣钱要数着写：成本、回款、利润分开交代；主角心里要有小账本（"进价八毛，卖一块五，一天能出六十碗"）
- 大额进账后接一句落袋动作（存折、锁抽屉、埋进米缸），钱的去向前后一致
- 亏损与风险同规格写清：亏多少、怎么亏的、谁背的锅
