# 开篇设计（黄金三章）

全书开篇的设计方法：黄金三章的任务分配、开篇即冲突、人设速立、忌堆设定，先钩住读者再铺世界。

## 为什么是前三章

读者（和编辑）用前三章决定去留。前三章的任务不是"介绍这个世界"，而是**建立期待**：让读者在意一个人，并想看他解决一个麻烦。

## 黄金三章任务表

| 章 | 核心任务 | 底线要求 |
|----|---------|---------|
| 第一章 | 主角登场 + 开篇冲突/悬念 + 露出核心看点 | 第一章结束前主角必须出场且遇事 |
| 第二章 | 冲突升级 + 立人设 + 暴露主角目标 | 读者能说出"主角想要什么、挡他的是什么" |
| 第三章 | 小爆发（金手指初显/初露锋芒/打脸）+ 引出更大世界 | 有一次情绪释放 + 一个更大的悬念钩子 |

第三章结尾的经典结构：小反转 + 初露锋芒——解决眼前危机的同时，让读者瞥见更大的世界（"你以为这只是宗门纷争？其实……"）。

## 开篇即冲突

第一段就要有事发生，制造**认知缺口**（读者知道得不够多，想知道）：

- 从冲突进行中的时刻切入，不要从"某年某月"或"主角起床"开始
- 首章必答三问：**他在哪（一句）**、**他要什么/怕什么**、**什么正在威胁它**
- 二十种强力开头技巧（行动中开场、反常情境、震撼对话等）见 chapter-guide.md 的"十种强力开头技巧"

### 首个冲突的五项硬指标

第一章的首个冲突要一次做到五件事，缺一件就虚：

| 支点 | 应该怎么写 | 坏写法 |
|------|-----------|--------|
| 立刻发生 | 第一章直接开场，可从冲突中段切入 | 铺垫到第三章才起冲突 |
| 有代价 | 给冲突设具体赌注：钱、脸面、机会、安全 | 赢了没奖励，输了没损失 |
| 能牵引 | 冲突背后站更大的对手/规则，胜负引出新麻烦 | 冲突结束世界恢复原状 |
| 立场清晰 | 用行动标明谁欺负人、谁占理，读者快速站队 | 各打五十大板 |
| 主角入局 | 冲突直接损害主角现有利益，想躲躲不掉 | 主角围观半章才被卷入 |

冲突里主角至少用 1 次算计或借力（而非纯拼等级），带智斗的冲突比硬拼耐看；禁止靠对手降智送人头取胜。

## 主角登场速写

- **动作中立人设**：让主角在第一个冲突中做一个选择，选择即人设——救不救、退不退、贪不贪
- **欲望 + 障碍**同时给出：他想要什么、什么东西挡在前面，这是期待感的发动机
- **一个记忆点**：外貌/习惯/口头禅取一个特征反复用，比面面俱到的外貌描写有效
- 禁止主角登场即全知全能；给他具体的困境（穷、弱、被欺、被逼婚、寿命将尽）

### 人设三要素 + 两配件（第一章内全部落地，靠行动展示不靠旁白宣布）

| 支点 | 应该怎么写 | 坏写法 |
|------|-----------|--------|
| 身份 | 一句话给职业、处境与当前困境 | 罗列头衔、家世、称号 |
| 欲望 | 说出一件具体想要的事（钱、物、一口气） | 抽象化为「想变强」 |
| 缺陷 | 给一个会惹麻烦的短板，并让它当场发作一次 | 缺陷只是萌点，从不产生代价 |
| 记忆点 | 可反复使用的标志性动作/口癖，第一章至少 1 次 | 记忆点是「冷静睿智」这类形容词 |
| 抉择验证 | 第一章安排一次小两难，选择出乎意料但合乎人设 | 全挑安全选项，没有棱角 |

三行立人的示范：第一行「长工陈九跪在雪里领月钱」，第二行他盯着当票说「我要赎回我娘的银簪」，第三行他当场拍出整月月钱换半张地契、明知会挨打——身份、欲望、缺陷、抉择一章落地。

## 金手指亮相：第一章亮相，最晚第三章生效

金手指是全书核心承诺，亮相连带试用与限制，缺一不可：

| 支点 | 应该怎么写 | 坏写法 |
|------|-----------|--------|
| 第一章亮相 | 第一章内让金手指出现并展示一次效果 | 先解释三章规则再开放使用 |
| 亮相即试用 | 当章让主角实际用出甜头（伤好了、钱到了、人怕了） | 只给面板不给体验 |
| 效果可视化 | 用具体变化呈现收益，不用修为/气运等抽象词 | 效果读者看不懂 |
| 留一条限制 | 亮相就带明显的限制或代价，无限制会杀死悬念 | 无所不能、什么问题都能解决 |
| 对症下药 | 第一效果正好解决主角第一章的眼前麻烦 | 能力再强但与当下困境无关 |
| 用法留白 | 只展示基础用法，隐藏用法留到后续解锁 | 开局把全部说明书抖完 |

## 三章内首次兑现：先给小甜头建立信任

三章内的第一次赢必须真实发生、且验证核心卖点：

| 支点 | 应该怎么写 | 坏写法 |
|------|-----------|--------|
| 三章内到账 | 第三章前完成一次明确的赢 | 第一次爽点拖到第五章后 |
| 小而完整 | 对手出现→施压→主角用底牌翻盘，走完整闭环 | 半截兑现，赢了没有下文 |
| 用底牌赢 | 翻盘关键必须是金手指或核心设定 | 靠运气、靠路人帮忙 |
| 兑现有观众 | 至少一人在场看到主角赢，爽感需要见证者 | 主角偷偷赢没人知道 |
| 代价铺垫 | 兑现前至少付出 1 项可见成本（挨打、破财、受辱） | 胜利白捡，没有分量 |
| 反应外化 | 写围观者惊呼、对手失态、评价反转 | 只写主角心里暗爽 |

兑现要走「压抑→代价→翻盘→见证」完整循环，不能只承诺不付货，也不能首次就掏空底牌。

## 开篇目标感：短期目标驱动前三章

- **短期目标**：前三章内一个具体可完成的目标，写进主角台词，带期限与阻力（「三天，十块灵石，给妹妹抓药」）
- **长期雏形**：第一章埋一句长期欲望（复仇/回家/登顶），只给一句不展开
- **目标有阻力**：每个目标至少配一个具体障碍；无阻力目标无张力
- **目标分层**：卷目标→段目标→章目标逐层咬合，下级服务上级
- **绑定金手指**：短期目标正好需要金手指的第一用法来实现，承诺闭环
- **定量化**：目标带数字与期限（三天、十块、八百里），进度可感知

目标公式：**具体物 + 期限 + 阻力**，缺一样就散架；禁止主角随波逐流被剧情推着走。

## 忌堆设定

开篇最忌世界观倾倒：

- ❌ 开篇整段介绍大陆格局、宗门历史、修炼体系——读者一个名字都记不住
- ❌ 配角成批登场、名字铺满第一页
- ✅ 世界观在冲突中**顺带**露出一角：用主角的困境暴露规则（"废灵根"三个字，比三百字介绍灵根体系更有效）
- ✅ 名字控制：首章有意义的名字 ≤5 个，其余用身份代称（管事、长老、师兄）

## 世界观的软性植入

- **规则服务困境**：先让主角被规则欺负，读者自然会想了解规则
- **一句一钉**：每个关键设定用一句话钉在冲突节点上，跨多章慢慢拼图
- **疑问即钩子**：抛出不解释（"他手腕上的旧疤，又烫了起来。"），悬念本身就是设定披露的载体

## 开篇与后续的衔接

开篇不能耗尽洪荒之力后面泄气：

- 第一章的冲突必须能**长出**第二章第三章的剧情，而不是一章内小打小闹解决后另起炉灶
- 前三章埋的悬念要支撑到第一个弧高潮（8-20 章），中途不能不了了之
- 开篇的强度是"基准线"：此后每章不低于这条线，只会更紧（对照 pacing-control.md 防止中期拖沓）

## 黄金三章后的节奏控制（防止用力过猛）

开篇最容易犯的错误不是拖沓，而是**用力过猛、节奏过快**——前三章建立期待后，第 4-5 章就把终极底牌全部亮出来，导致后续无戏可唱。

### 用力过猛的典型症状

- 第 5 章之前主角就击败了比自己高 2 个大层级以上的对手（如练气期秒杀金丹）
- 第 5 章之前就揭示了终极世界观真相或最终Boss身份
- 开篇建立的金手指/系统在 3 章之后就消失或被遗忘
- 主角的重大心态转变（如从逃避到面对）没有足够的内心挣扎，一句话就完成
- 敌人强度递进断裂：开篇小喽啰之后直接跳到最终Boss，缺少中间层级

### 第 4-10 章节奏基准线

| 章节范围 | 节奏定位 | 核心任务 | 敌人强度 |
|---------|---------|---------|---------|
| 第 4-6 章 | 稳步推进 | 冲突升级+立人设+暴露主角目标 | 小头目/中层干部 |
| 第 7-10 章 | 第一个小高潮 | 金手指初显+初露锋芒+引出更大世界 | 比主角强 1 个大层级的对手 |

- **第一个真正的大高潮应该在第 8-15 章左右**，不能在第 5 章就把终极底牌亮出来。
- **世界观揭示要分层**：前三章只露出冰山一角（主角的困境、局部规则），更大的世界（大陆格局、顶级势力、终极威胁）在第 10 章以后逐步揭示（与 worldbuilding.md 设定披露三层结构联动）。
- **主角的实力提升要有过程**：每次实力提升必须有明确的机缘、代价和验证过程，不能突然变强（与 worldbuilding.md 升级体系防崩盘联动）。
- **金手指/系统规则仅在存在时启用**：只有开篇或故事设定明确建立了金手指/系统，才要求后续持续发挥作用并每 3 章至少使用或有意义提及；没有该设定的故事跳过本条，不得为了满足频率要求临时添加外挂。

## 开篇流派选择：四种开局各有适配题材

选流派比堆技巧重要：流派要按题材与能力半径对号入座，错配的流派写出的是缺点而不是风格。

| 流派 | 适配与原理 | 应该怎么写 | 坏写法 |
|------|-----------|-----------|--------|
| 冲突直入型 | 快节奏爽文，对抗即钩子 | 第 1 章冲突当场发生，主角当场回应 | 冲突拖到第三章 |
| 金手指先行型 | 系统流升级流，卖点先亮 | 第 1 章金手指出现并完成一次试用 | 金手指当设定藏 |
| 身份反差型 | 马甲文赘婿文，落差即期待 | 开局立双面身份与受压处境，亮牌留后 | 反差靠旁白解释 |
| 回溯型 | 重生文复仇文，先知即爽点 | 开局交代重生节点与第一个先知变现 | 回溯背景交代三章 |

- 流派自检三条：流派承诺是否三章内小兑现过一次？辅助元素是否抢过主流派镜头？写到第十章读者能否用一句话说出这本书属于哪一派？
- 反差流吃伏笔功底，回溯流吃大纲能力；一段开局只能有一个主焦点，禁止多流派平均混用
- 中途禁止更换流派（读者按开局契约进来）；结局流派承诺全部兑现并回扣开篇第一幕
- 区域选择（pattern 016 开篇场景）：开场场景必须同时承担"冲突现场 + 人设展示场"两个功能，选择主角最输不起的场合（大比擂台、家宴、拍卖会），让主角的处境在该场合被公开压到最低点

## 常见开篇死法与自查

| 死法 | 症状 |
|------|------|
| 天气/起床/吃饭开场 | 无冲突，三秒划走 |
| 设定倾倒 | 名词轰炸，读者记不住 |
| 配角开场 | 三千字了主角还没出现 |
| 回顾式开场 | "上一章/前世……"，读者没有前世记忆 |
| 冲突无关化 | 开场冲突与主线无关，三章后换故事 |

- [ ] 第一段是否有事件正在发生？
- [ ] 第一章主角是否出场并做出选择？
- [ ] 三章内读者能否说出：主角要什么、挡路的是什么、他凭什么（金手指）？
- [ ] 首章有意义名字是否 ≤5 个？
- [ ] 有没有整段设定介绍混入前三章？
