# 环形结构（Circular Structure）

故事的结局精准回到开头设定的情境、意象或预言，首尾相接形成一个闭环；常用来表达宿命感、时间轮回或历史重演（如《百年孤独》开头预言与结尾应验、《牧羊少年奇幻之旅》以同一句开场白收束、循环流作品如《开端》）。

## 章节分解

```text
第1章：   设定一个"起点意象/预言/提问"（读者未必察觉其重量）
第2-8章： 线性推进主体故事（中段可正常按三幕/五幕节奏走）
第9-10章：结局 —— 回到开头的意象/场景/那句话，但意义已完全改变
```

## 关键

- 开头元素必须"足够轻却能承重"：既是普通细节，又是结局的解码钥匙
- 回环要制造"原来如此"的重读感，而非机械复读
- 适用于宿命、轮回、遗产、执念等主题，天然贴合因果报应题材
