# 碎片化叙事（拼图式，Fragmented / Jigsaw Narrative）

刻意打破时间和空间的连贯性，把事件以碎片形式呈现；读者需要像拼图一样，在阅读过程中自行拼凑、补白、还原出全貌（如《云图》跨越时空的六段故事、《佩德罗·巴拉莫》以碎片拼出亡灵之村的死亡史、《记忆碎片》的倒置碎片）。真相不在文本表面，而在读者完成拼合的那一刻。

## 碎片组织要点

```text
碎片1：结局/中段的一个截面（先给"果"，后补"因"）
碎片2：另一时间线/视角的片段（视角、时代切换）
碎片3-5：交错抛出关键事件的不同视角与不同时间点
碎片6：收束碎片 —— 让部分线索重合，露出拼图全貌
```

## 关键

- 每个碎片自身必须成立（有钩子、有人物动作），不能依赖"下一片来解释"
- 为每片预留"可被重新解读"的留白：信息刻意缺角，但逻辑链条不能缺
- 拼合点应带来情绪/认知的高潮，而非仅仅是"时间线对上了"
- 风险：理解成本高易劝退读者；需用强人物或强氛围补偿
