# 套盒结构（戏中戏，Frame / Nested Story）

故事里套故事，一个大的叙事框架内嵌套次级故事，层层打开如俄罗斯套娃（略萨称之为"中国套盒"）。外部故事常只是引子/讲述场景，真正的核心在内层，或在内层与外层之间的映照里（如《一千零一夜》山鲁佐德夜夜讲故事求生、《呼啸山庄》洛克伍德转述耐莉的回忆、《坎特伯雷故事集》与《十日谈》的群体讲述框架、《盗梦空间》的梦中梦）。

## 层次分解

```text
第1-2章： 外框（讲述者/引子：谁在什么处境下要听或讲一个故事）
第3-8章： 内层主故事（可再嵌套更深一层）
第9-10章：回到外框 —— 内层故事改变了讲述者/听众（意义反转）
```

## 关键

- 外框不能只是"端故事的盘子"——讲述者的处境必须与内层故事互文（山鲁佐德靠讲故事续命、洛克伍德被故事触动）
- 层与层之间要互相映照：内层解决外层的问题，或外层揭示内层的真义
- 层次克制：超过三层读者易迷失；每层切换要有清晰记号
