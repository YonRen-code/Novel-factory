# 起承转合（四幕式结构，Kishōtenketsu）

源自中国古典诗论（绝句"起承转合"），后传入日韩称"起承転結 / 기승전결"，是东方叙事最常见的骨架。与西方三幕式"以对抗冲突为引擎"不同，起承转合的核心特色在第三段"转"——引入一个看似无关的新元素或新视角，最后在"合"中与主线交织出新的意义。它更注重故事内部的韵味和意想不到的转向，而非正反双方的正面较量（如宫崎骏《龙猫》的无反派叙事、《寄生虫》第三幕的换轨）。

## 四段分解

| 段 | 功能 | 内容 |
|----|------|------|
| 起（Ki） | 引入 | 建立人物、场景、基调 |
| 承（Shō） | 发展 | 顺势铺开，加深细节与情境 |
| 转（Ten） | 转折 | 引入看似无关的元素/视角，重构对前文的理解（重在换位与换境，不一定是敌我冲突） |
| 合（Ketsu） | 归结 | 收束，让"转"与前面所有线索交织成整体意义 |

## 写作提示

- "转"不要写成半路杀出的反派，而是一次认知升级或情境翻转——好的"转"让读者回看"起/承"时恍然大悟
- 不必强行安排正反对抗；主题是"发现联系与韵味"而非"战胜对手"
- 结尾宜快、宜留余味，勿拖沓说教
