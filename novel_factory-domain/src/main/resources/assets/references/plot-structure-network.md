# 多线并行（网状结构，Braided / Network Structure）

同时推进几条不同的故事线或多个角色的主观视角（POV），各线看似各自为政，最后在故事的终点交汇、互相印证或碰撞（如《冰与火之歌》的多 POV 群像、《低俗小说》的交叉叙事、《罗生门》的同一事件多视角）。比基础交叉剪辑更进一步：每条线各有完整弧光，交汇前彼此埋有暗扣。

## 章节分解

```text
第1-2章： 并行铺开两条以上主线（各自 POV、各自目标）
第3-6章： 各线内部推进 + 偶发暗扣（看似无关的事件实为伏笔）
第7-8章： 线间第一次交集/误判/错位
第9章：   多线汇合，前文信息互相解释、碰撞出新的意义
第10章：  汇合后收束（可留一线伏笔给续作）
```

## 关键

- 每条线都需要独立的"想要 + 阻碍"，避免沦为陪衬
- 交汇必须改变各线走向，而不是各讲各的拼盘
- 控制线数：长篇 3-5 线、短篇 2 线为宜，超过则读者负担过重
