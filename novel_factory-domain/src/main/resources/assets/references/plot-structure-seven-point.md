# 七点结构（Seven-Point Story Structure）

由科幻作家丹·威尔斯（Dan Wells）推广的节奏骨架，用七个"功能位"卡住读者情绪，短篇长篇皆宜；最大特色是**从结局倒推设计**——先定结局，再由钩子/中点/转折反推，保证开头与结尾的承诺一致。适合类型网文的中长篇节奏推进。

## 七点定位（钩子 → … → 结局）

| 点位 | 功能 | 自检提示 |
|------|------|---------|
| 1. 钩子 Hook | 主角起点状态（通常是终态的镜像/反面） | 起点与终点能看出改变吗？ |
| 2. 转折点1 Plot Turn 1 | 激励事件，把故事推出起点状态 | 局面真的变了，还是只有心情变了？ |
| 3. 压力点1 Pinch 1 | 阻力首次展示实力，主角被迫行动 | 有没有"不得不做"的代价？ |
| 4. 中点 Midpoint | 主角由"被动应对"转为"主动出击" | 此后他是否在推进自己的计划？ |
| 5. 压力点2 Pinch 2 | 压力最大，计划失败、助力被剥离 | 是否已无路可退、无援可用？ |
| 6. 转折点2 Plot Turn 2 | 主角获得决胜所需的最后一块（多为关键认知） | 这信息此前是否"挣到过"？ |
| 7. 结局 Resolution | 高潮 + 人物改变的落地 | 是否用上了转折点2给的东西？ |

## 使用要点

- 按"结局 → 钩子 → 中点 → 两个转折 → 两个压力点"的顺序反推设计，可防止"结尾解决的是另一个问题"
- 区分压力点与转折点：转折点是剧情机器换挡，压力点是外力对主角施压
