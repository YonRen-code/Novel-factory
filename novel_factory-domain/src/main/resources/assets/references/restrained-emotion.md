# 克制与隐忍的情感描写

克制隐忍型情感的表达技法：陈词滥调替换、微动作/视线/感官/语言四类替情手段，以及沉默须伴随保护性行动的角色逻辑。

## 陈词滥调禁用与替换

以下身体反应套话是"隐忍"场景的复读机重灾区（与规则 anti-ai-tone 联动），同一角色同一套话全篇至多出现一次，优先用后文四类手段替换：

| 陈词滥调 | 替换方向 |
|---------|---------|
| 喉结滚动 | 声音变化：比平时慢半拍、低了半度、清嗓后才说出口 |
| 呼吸一滞 | 动作停顿：手上的动作停了半拍，续上时放错了步骤 |
| 心口一沉/一揪 | 注意力逃逸：突然认真听旁边无关的对话、反复看表 |
| 指节攥白/拳头攥紧 | 用力转移：把纸巾叠成小方块、瓶盖拧过了头 |
| 深吸一口气 | 动作冗余：把已经齐整的纸重新对齐一遍 |
| 身体僵住/如遭雷击 | 反应延迟：对方说完三秒后，他才"嗯"了一声 |
| 眼底闪过一丝XX | 视线落点（见下节） |

## 微动作：情绪的泄压阀

克制的人物没有大动作，情绪从**无意识的小动作**里漏出来：

- 小动作三特征：**无意识、重复、与当前场景功能无关**——捏紧衣角、转动笔尖、摩挲杯沿、把玩打火机却不开火
- 情绪定动作家族：压抑愤怒→过度平静的整理动作；隐忍悲伤→照常做事但变慢、出错；克制心动→下意识拉开距离、把注意力塞进无关物体
- 反向用力：表面越平静越轻反而越用力——关门关得很轻，拧把手的手背绷起了筋
- 同一动作每章至多两次（对照 anti-ai-tone 生理反应复读机判据）；重要人物可固定一个"习惯性小动作"作为身份标记，但出现频率同样受限

## 视线：落点即心理

克制情绪大量写在"看什么、不看什么、看多久"：

- **不敢看的落点**：目光落在对方锁骨以下的位置、盯着茶杯里的倒影、看对方身后墙上的挂历
- **移开的方式带信息**：移得太快（心虚）、舍不得移（贪恋）、被察觉后瞬间转头假装看别的
- **凝固与追随**：视线钉在某个点不动（被戳中），或不受控地追随某人（被自己发现后强行收回）
- 禁止"眼底闪过一丝XX"式命名情绪，直接写落点与时长

## 感官主观化：情绪扭曲感知

用"世界变了样"写"他变了"，情绪改变感知的音量、流速与温度：

- **放大**：挂钟的走针声突然很响、冰箱的嗡鸣盖过了对方的话
- **缩小**：对方的话像隔着水传过来、满街人声忽然听不见了
- **流速**：一分钟的沉默长得像一小时；或整晚怎么过去的完全没有记忆
- **温度/触感**：手心发烫、指尖发凉、贴身衣物忽然处处硌人
- 单场景选一种失真即可，不叠加（对照 scene-writing 五感聚焦法）

## 语言行为：克制者怎么说

克制人物的回避与沉默本身要有戏：

- **突然的沉默**：给沉默时长与填充动作——"他没接话。茶凉了半盏的工夫，他在给炉子添水。"
- **转移话题**：转向具体的、琐碎的、与情绪无关的事（突然问"你吃饭了吗"），转折越硬说明刚才那句戳得越准
- **答非所问/以问代答**、过度礼貌（礼貌即距离）、字数骤减、话说半句自我改道
- **间接生理信号**（替代呼吸一滞类）：在某个词前后停顿、开口又合上、把一句话咽下去换成另一句

## 沉默必须伴随保护性行动

隐忍角色的核心逻辑：**沉默是省略语言，不是省略行为**。只写"他不说话"是空的，必须配上正在进行的保护性动作：

| 沉默伴随的保护性行动 | 传达的信息 |
|---------------------|-----------|
| 把身边人往身后带半步 | 在扛危险 |
| 抢先结账/把责任揽到自己身上 | 在扛代价 |
| 连夜转移证据/把人送出城 | 在扛风险 |
| 第二天照常做早饭、照常出摊 | 在扛生活 |

- 沉默 + 行动才是完整的"隐忍"：不说，但他在替人挡
- 保护对象与隐瞒对象要一致：他的谎只骗"会伤害他守护对象的人"，不为制造误会乱撒谎

## 被逼问时的部分真相释放

克制角色被逼到核心问题时，**不能永远用模糊言辞原地打转**：

- 每次逼问，谜团必须缩小一圈：给出**可承受的部分真相**——具体的苦衷、伤疤的来历、某笔钱的去向、某通电话的存在，同时保留最核心的一层
- 释放精度递进：第一次给现象、第二次给原因、第三次给细节，层层剥开本身就是节奏（对照 foreshadowing 回收周期）
- 回避要有成本：模糊言辞付出即时代价（对方失望、误会加深、关系裂痕），免费回避等于注水（对照 pacing-control 原地打转识别）
- 半真半假的边界：克制者说出口的部分必须全部为真（后续复盘经得起查），只是不完整——"我从不说谎，我只是不说"

## 克制的阈值与爆发

隐忍不是无限忍：

- 强度分级定手段：轻微→微动作/视线落点；中等→感官主观化/沉默与转题；强烈→部分真相释放/保护性行动升级/行为反差
- 爆发点提前埋（压抑段不超过 3 章，对照 emotion-curve 压抑配比），爆发的**形式符合人设**：克制者的爆发往往不是嘶吼，而是极端平静地做完一件事——把东西一样样放回原位、平静地说完狠话、转身把门带上
- 爆发后的回缩：第二天若无其事，但某个习惯性小动作变了——读者知道有什么再也回不去了
