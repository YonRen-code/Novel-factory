# 场景与感官描写

场景描写的沉浸感技法：五感聚焦、动态化、展示而非讲述的落地判断，避免模板化写景与信息倾倒。

## 展示而非讲述：落地判断法

"讲述"是直接给结论；"展示"是给出读者能自己得出结论的证据。

**判断标准：这句话能不能被一台摄像机拍到？**

| 讲述（禁用） | 展示（改写） |
|-------------|-------------|
| 他很紧张。 | 他把杯沿转了三圈，没喝一口。 |
| 她很生气。 | 她把筷子拍在桌上，起身时带倒了凳子也没回头。 |
| 集市很热闹。 | 卖糖人的敲着铜勺吆喝，两辆骡车在巷口顶上了牛，谁也不肯先退。 |
| 他是真的怕了。 | 他后退半步，后腰抵住了桌角。 |

- 情绪用**行为证据**呈现（动作、生理反应、微表情），不直接命名情绪
- **例外**：过渡性信息、时间跨度交代可以用讲述快速带过——关键场景用展示，过场用讲述，二者混合使用

## 五感聚焦法

- **单场景聚焦 1-2 种感官**：贪多必失焦。选定最贴合场景情绪的感官重点写
- 常规是视觉，但**非常规感官**记忆点更强：气味（最容易触发联想）、声音（营造氛围）、触觉（亲密与痛感）、温度
- 感官细节要**属于这个场景独有**：不是"有声音"，而是"什么声音"

```
弱：演武场很吵。
强：演武场上兵刃相撞的脆响混着观众的起哄，场边战马打响鼻的声音都传不进来。
```

## 动态化：让场景活起来

- **静物是画面感的天敌**。景色不要罗列，让它动起来：
  - 弱：山间有雾，很安静。
  - 强：雾从谷底漫上来，把半截石阶吞了。有人踩碎一颗枯果，惊起两只山雀。
- **用动词承载描写**：角色在动，环境跟着动（衣摆带风、踏碎积水、撞开人群）
- **环境给反馈**：角色进入场景，场景要回应他（门轴吱呀、人群安静下来、狗吠了两声）

## 环境烘托情绪

写景的目的是写情，情景交融而非孤立的风景画：

- **同景异情**：同一个渡口，赴任时写"晨光把江面照得发亮"，逃亡时写"江水浑得像化不开的墨"
- **用景写心**：不写"他心乱如麻"，写他望着雨点砸碎水面上的灯影
- **感官通感**：心虚时觉得四周的凉意都往领口里钻

## 镜头感

像运镜一样控制描写的视线：

1. **远景定调**（一句）：城、山、天气
2. **中景带人**：主角进入，环境如何回应
3. **特写聚焦**（1-2 个）：与本章冲突相关的具体细节——刀柄上的缺口、对面掌心的汗

特写是镜头感的灵魂：**选 1-2 个有叙事价值的细节怼近了写**，其余全部略过。什么细节有叙事价值？它能暗示冲突、人物或伏笔。

## 描写的取舍

每个描写段落必须至少服务一项，否则删：

- **推进剧情**：这个细节后面会用到（伏笔/线索）
- **塑造人物**：这个细节暴露了谁的性格或状态
- **营造氛围**：这个细节建立了本段的情绪基调

环境描写总量建议：场景开头 2-4 句 + 需要时穿插一句，**不连续超过 6 句纯景物**。

## 常见模板句病

以下句式是 AI 味重灾区（详见规则 anti-ai-tone），出现即改写：

| 模板句 | 病因 |
|--------|------|
| "阳光透过树叶洒下斑驳的光影" | 万金油写景，任何场景都能套 |
| "空气中弥漫着…的气息" | 高频句式，全篇至多一次 |
| "他的眼中闪过一丝…之色" | 用眼神直接命名情绪，讲述非展示 |
| "仿佛整个世界都安静了下来" | 夸张空泛 |
| 连续排比铺陈景物 | 信息倾倒，读者跳过 |
| "夜色如墨"/"月光如水"/"星光璀璨" | 写景套话，无场景独有性 |
| "灯火通明"/"人声鼎沸"/"熙熙攘攘" | 万金油场景描写，任何热闹场景都能套 |
| "车水马龙"/"川流不息"/"络绎不绝" | 成语堆砌写景，无具体细节 |
| "微风拂过"/"清风徐来"/"风轻轻吹过" | 无信息量的写景填充，删除不影响场景 |

## 自查清单

- [ ] 关键情绪是否全部用行为证据呈现，没有直接命名？
- [ ] 本场景是否聚焦了 1-2 种感官而非泛泛的视觉？
- [ ] 景物是否动起来了，有没有连续 3 句以上的静态罗列？
- [ ] 特写细节是否有叙事价值（暗示冲突/人物/伏笔）？
- [ ] 有没有模板句混入？
