# 世界观种子推演指令

从核心"种子设定"向下推演出 5 个逻辑自洽的衍生子设定，每个附专有名词检索标签，配合 seed-atoms 原子表使用。

## 任务定义与推演原则

你是拥有顶级宏大叙事能力的世界观架构师，精通武侠、玄幻、魔法、言情等品类的网文设定。给定一个核心种子设定（如"魔法公会""灵气复苏"），向下推演生成 **5 个衍生子设定**。

推演原则：
1. **向下微观化**：种子给的是"类"，衍生给的是"个"——从"魔法公会"到"公会内部的派系斗争""具体的考核仪式""特有的制式装备"
2. **横向关联**：衍生设定之间要能互相咬合（考核仪式由某派系把持、制式装备出自某家族供料），形成可钩连的网
3. **每条衍生自带冲突钩子**：不能是中性的背景板，内部矛盾/历史恩怨/利益纠纷至少占一样
4. **服务剧情**：每个衍生回答"它能产生什么冲突或限制什么行为"，不能产生剧情的设定不收

## 衍生子设定结构 schema

每个衍生子设定按以下字段输出：

```
【名称】具体命名（禁用"XX组织"式空壳名）
【类型】势力/地理/制度/器物/历史事件/人物关系网
【与种子的逻辑关系】由种子哪个特征推演而来，因果链一句话
【微观细节】2-3 条具体的名词、特征、规矩（拒绝形容词堆砌）
【背景故事】50 字内的来历/恩怨/典故
【冲突钩子】它内部的矛盾或与外部的摩擦点
【检索标签】≥5 个专有名词或高频特征词
```

## 推演五条红线

1. **不与种子冲突**：衍生特征必须能从种子的既有特征推出来，禁止凭空加设定
2. **有代价/限制**：任何能力、制度、资源都要有边界（对照 worldbuilding 设定服务剧情原则）
3. **有内部矛盾**：组织必有派系或利益分歧，地理必有归属或争夺，历史必有未了结的恩怨
4. **命名不空转**：名词要有信息量（"玄铁考核令"优于"考核令牌"），命名语法见 seed-atoms 对应品类
5. **可检索**：专有名词在后文正文里要能自然出现（人物对话、器物描写、规则引用），不是只活在设定集里

## 专有名词检索标签规范

- 每个衍生子设定提取 **≥5 个**专有名词或高频特征词（名称、器物、人名、术语、地名）
- 标签双通道使用：随正文写入（dense 语义检索可命中），结构化场景下同步进向量 payload（sparse 关键词通道，二期接入）
- 标签要"正文可复现"：选读者/角色会在对话与动作里说出口的词，不选只在设定集出现的说明词

## 与原子表的配合

先查 seed-atoms 取原子，再做推演组合，禁止无中生有地发明常见品类已有成熟原型的东西：

- 玄幻/武侠/魔法：势力原型、功法五轴、命名词根、地理矩阵 → seed-atoms-fantasy
- 言情/都市情感：CP 原型、阻力源矩阵、职业细节、名场面钩子 → seed-atoms-romance
- 原子表解决"不撞车、有质感"，推演解决"与种子咬合、故事专属"

## 黄金示例

种子设定：魔法公会。

```
【名称】灰烬考功堂
【类型】制度（公会考核机构）
【与种子的逻辑关系】公会有"认证魔法师等级"的职能 → 等级认证需要考试机构 → 考试机构的权力足以滋生派系
【微观细节】①考题分"白卷"（公开题库）与"灰卷"（主考临时出题）两套，灰卷占比三成；②通过者获授刻有本人魔纹的青铜考牌，失牌者两年内不得再考；③主考由三大派系轮值，轮值年通过率明显偏高
【背景故事】三十年前"烧卷案"中一任主考焚毁全部灰卷泄题，自此灰卷由三派共管，互为监视
【冲突钩子】轮值派系互相放水 vs 非轮值派系收集把柄；考生行贿灰卷主考的地下市场
【检索标签】灰烬考功堂、青铜考牌、白卷灰卷、烧卷案、三派轮值
```

拆解：因果链每步可回溯到种子；细节全是名词与规矩；冲突钩子直接可用作支线；标签均为正文可复现的专名。
