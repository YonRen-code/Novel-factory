## 功法类型学：五轴组合

功法实例 = 属性 × 品阶 × 载体 × 功能 × 代价。轴的取值：

- **属性**：金木水火土 / 风雷冰 / 暗光 / 空间 / 时间 / 音 / 梦 / 血
- **品阶**：黄→玄→地→天（可各分上中下），或典籍分级：口诀→心法→真经→圣册→天书
- **载体**：剑 / 刀 / 指 / 掌 / 腿 / 步法 / 身法 / 诀（心法）/ 经（典籍）/ 阵
- **功能**：攻 / 防 / 炼体 / 身法 / 神识 / 炼丹辅修 / 驭物
- **代价**：燃血 / 折寿 / 心魔 / 反噬 / 情绪剥离 / 五感代偿

每个实例按四字段落地（这就是"练气期到大乘期的具体表现、走火入魔症状、克制关系"的落点）：

```
【境界表现】练气期→金丹期→大乘期各阶段的外显特征（一层一个画面，禁止只写"更强"）
【入魔症状】过度催发的具体身体/心性异变（可观测、可递进）
【克制关系】被什么属性/手段克制，克制逻辑必须说得通（水克火≠万能，要有具体机理）
```

**完整示例**（质量锚点）：

1. **《赤霄焚海诀》**（火属性·地阶·诀·攻·燃血）：练气期掌心生火只能燃纸；金丹期可蒸干方圆十丈水汽；大乘期引动地火焚海，一击之后经脉如遭火焚，三月不能用武。入魔症状：先瞳孔泛赤、后体温常人两倍、终至七窍生烟而神智仍清（燃血过度）。被"玄冰锁脉手"克制——寒气封穴使血气燃不起来。
2. **《听雨剑经》**（水属性·玄阶上品·剑·身法兼攻·五感代偿）：练气期剑速如檐雨滴落；金丹期剑出如骤雨连绵；大乘期一剑落下如江海倾盆。代价是听觉逐级钝化——大乘期修士多是聋子，靠剑气感知世界。入魔症状：幻听先至，把雨声听成亡者低语。克星是"锁灵指"封耳后其剑感尽失。
3. **《周天搬运功》**（无属性·黄阶·经·炼体·无）：练气期强身健体；金丹期皮糙肉厚刀枪难入；大乘期肉身成圣。但无属性意味着无法借势越级——它是所有功法里"最稳也最慢"的基准线，常作配角与反派杂兵功法。

## 命名语法与词根库

命名公式：**境界/属性意象 + 功能载体 + 数字量词/程度后缀**

| 词类 | 词根池 |
|------|--------|
| 属性意象 | 赤霄、玄冰、听雨、惊蛰、白露、裂空、碎星、镇岳、青冥、九幽 |
| 品级意象 | 天、玄、混元、大衍、太上、无极 |
| 载体 | 剑、刀、枪、指、掌、拳、步、身法、诀、经、录、典、手、功 |
| 数字量词 | 一、三、九、三千、周天、大千 |
| 动词性词根 | 焚、裂、镇、锁、截、断、引、渡、化、吞 |

拼装示例：镇岳掌（土·攻）、三叠浪刀（水·三段击）、九幽渡魂经（暗·神识）、大衍焚天诀（火·天阶）。**禁用**"至尊神功""无敌心法"等无信息量命名。
