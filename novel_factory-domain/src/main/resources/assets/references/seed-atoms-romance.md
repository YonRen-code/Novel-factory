# 言情设定原子表

CP 关系原型与阻力源矩阵、职业细节库、名场面钩子库——组合生成故事专属感情线设定的元素周期表。

## CP 关系原型库

每个原型自带核心张力与天然阻力，取用后与种子设定咬合：

| 原型 | 核心张力 | 天然阻力 |
|------|---------|---------|
| 敌对立场 | 立场相反而心渐靠近 | 任务与感情的零和 |
| 双向暗恋 | 都心动都不说 | 自卑/身份顾虑/不信被爱 |
| 契约先行 | 假戏真做的边界感 | 协议到期、旁人拆穿 |
| 先婚后爱 | 义务里长出的心动 | 无感情基础的磨合、旧情人 |
| 破镜重圆 | 旧伤与新动的拉扯 | 当年分手的真因未除 |
| 救赎系 | 一人拉另一人出深渊 | 被救者的自我放弃、救者耗竭 |
| 竞争对手 | 棋逢对手的惺惺相惜 | 只有一个名额/一个位置 |
| 身份差 | 阶层/年龄/师徒的禁忌感 | 外部眼光、前途代价 |
| 伪装身份 | 用假身份动了真心 | 揭穿的必然性与时机 |
| 旧识新遇 | 记忆里的人和眼前人重合 | 童年误会、各自的成长代偿 |
| 守护者 | 一直站在身后的那个人 | 主角眼里只有别人 |

## 阻力源矩阵

误会与考验 = 内因 × 外因的组合，取用时**内外各一**，纯外因像狗血，纯内因像抑郁：

| 内因（性格/认知） | 外因（环境/他人） |
|------------------|------------------|
| 旧伤形成的回避型依恋 | 家庭的债务/病床/政治联姻 |
| 不配得感（自我攻击） | 职场晋升的零和竞争 |
| 控制欲/完美主义 | 阶层或地域的现实差距 |
| 价值观硬冲突（钱/义/家） | 情报不对称（被蒙蔽/被裁剪的事实） |
| 责任过度（习惯性扛一切） | 第三方的真实魅力与合理追求 |
| 表达障碍（越在乎越说反话） | 时机错位（一方刚下定决心另一方远行） |

组合示例：表达障碍 × 情报不对称 → 心动从不出口，又被裁剪的事实坐实"他根本不在乎"→ 虐点成立且双方都没错。

## 职业细节库

职业决定日常质感与冲突接口，取用时至少带走两条**专属细节**：

| 职业 | 专属细节钩子 |
|------|-------------|
| 古籍修复师 | 补纸要比原纸薄、浆糊自己熬、修旧如旧的职业伦理 |
| 外科医生 | 术前念患者名字、术后手抖只在下手术台后出现 |
| 建筑设计师 | 图纸比例、旧城勘测、验收日的忐忑 |
| 调香师 | 前中后调、气味记忆、配方是商业机密 |
| 刑警/法医 | 值班手机永不开静音、案卷不进家门 |
| 电竞选手 | 手腕伤、版本更迭、退役年龄的倒计时 |
| 翻译 | 舌头打结的深夜、文化不可译的沮丧 |
| 烘焙师 | 凌晨三点的面团、失败批次的处理、季节限定的菜单 |
| 天气预报主播 | 播报误差的舆论、出镜妆、台风夜连线 |

## 名场面钩子库

场景钩子 + 情绪功能，取用后必须装进本书的具体设定（避免万金油化）：

| 钩子 | 情绪功能 | 用法要点 |
|------|---------|---------|
| 雨夜共檐 | 心动/和解 | 雨是封闭空间的理由，出雨即散场，倒计时自带张力 |
| 医院走廊 | 脆弱/托付 | 手术灯是情绪开关，等结果的人最真 |
| 车站/机场 | 错过/追回 | 开车前十分钟是说与不说的最后窗口 |
| 婚礼（他人的） | 触动/试探 | 别人的誓词照见自己的心 |
| 旧居/母校 | 溯源/共情 | 童年细节是打开心防的钥匙 |
| 天台/楼顶 | 崩溃/接住 | 高度即危险，"你先下来"是关系的分水岭 |
| 醉酒 | 失防/真心 | 酒后吐真但次日必须付出尴尬代价，白嫖真心=降智 |
| 电梯困局 | 强制相处 | 空间越小对话越诚实 |
| 深夜便利店 | 日常感/落脚 | 热食与灯光是治愈系的物质载体 |
