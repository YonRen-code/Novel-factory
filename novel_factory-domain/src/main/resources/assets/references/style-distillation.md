# 文风提取编译法

从少量投喂样本中抽取可执行的文风特征，编译成"风格卡"供生成时注入。与 corpus-distillation.md 分工：蒸馏方法取**结构信息**（钩子/亮相/对白/结尾怎么物化摘录），本文取**写作风格信息**（句式节奏/叙事方式/用词习惯怎么量化约束）。核心原则：写法是"怎么把话说出来"的规则，不是"说了什么"的结构。

## 一、样本投喂：少量、标注、来源

- 每本书 3~5 段样本足够。太多会让特征"平均化"——失去个性。
- 每段样本标注来源（作品/章节/作者/题材）+ 一句"想学的是什么"（如"开头这段的悬疑感"）——标注决定抽取时采样概率与侧重点。
- 样本应覆盖想复制的风格全貌：至少一段叙事、一段对话、一段情绪高点。

## 二、客观统计（可量化的硬指标）

对样本做纯统计，生成客观特征，这些不靠 LLM 判断，直接算：

- 平均句长（汉字）+ 句长标准差（是否长短交替）
- 平均段长（句数）+ 标准差
- 标点频率：句号/逗号/分号/破折号/引号/感叹号/问号/省略号各自占比
- 对话占比（引号内字数 / 总字数）
- 词频 top 30（排除停用词后，观察高频词暴露的口头禅级偏好）

客观特征的作用：给风格约束提供**可测量锚点**（如"破折号在本样本中占比 0.00 → 编译为禁止"），防止全凭主观。

## 三、主观特征（靠 LLM 抽取，但要结构化）

让 LLM 看样本，按四个 category 提取 8~15 条特征，每条带：

- `weight 0~1`：这条特征在样本里的稳定程度（出现频率高 + 一致 = 高 weight）
- `rule`：一句话可执行规则，**不要泛泛而谈"语言生动"**——要具体说"用什么方法做到生动"
- `example-good`：样本中的正面例证
- `example-bad`：反例（可虚构）

四个 category 缺一不可，**每个至少 2 条**：

| category | 管什么 | 好规则示例 |
|---|---|---|
| narrative | 叙事方式 | "用动作和神态表现情绪，不用形容词直述" |
| character-voice | 角色表达 | "主角内心 OS 多，常用反问" |
| language | 语言习惯 | "段落控制在 3 句话以内" |
| rhythm | 节奏 | "长短句交替，长句用于铺垫、短句用于转折" |

## 四、编译：按 weight 分档措辞

同一特征按权重强弱决定指令强度，**不是所有特征同样力度**：

| 权重区间 | 档位 | 措辞 |
|---|---|---|
| 0.85~1.00 | 高强度 | "必须 / 禁止 / 不得 / 只能" |
| 0.65~0.84 | 中强度 | "优先 / 注意避免 / 警惕" |
| 0.30~0.64 | 低强度 | "尽量 / 倾向 / 可适当" |
| < 0.30 | 不编译 | 太弱，不出输出 |

示例同一条规则在不同档位的编译结果（"禁止解释心理"）：
- 高强度：`禁止直接解释人物心理，不得使用"他感到""他意识到"等表达`
- 中强度：`尽量不要直接解释人物心理，优先通过动作和对话体现情绪`
- 低强度：`心理描写倾向于行为化，可适当保留少量直接陈述`

## 五、反 AI 规则三段结构

抽取风格的同时维护一份反 AI 清单，分三档：

- **forbidden（绝对禁止）**：AI 特征句式（"不是.+而是"）、破折号、学术报告腔（"值得注意的是/核心在于"）等，weight 固定 1.0
- **risk（频次监控）**：如 "突然|忽然|猛然" 每 3000 字最多 1 次；"似乎|可能|或许" 每 1000 字密度上限 3——**不禁止，但限频**
- **encourage（鼓励出现）**：如"感官描写每场景至少 2 类""用具体细节而非抽象总结"

## 六、按任务类型装配（同一个风格卡，不同用途不同力度）

| 任务 | 写法规则强度 | 反 AI 强度 | 自检 | 额外约束 |
|---|---|---|---|---|
| 新章正文 | 强 | 强 | 开 | 字数目标 |
| 续写 | 强 | 强 | 开 | "保持前文气质，禁止突然升华" |
| 润色 | 中 | 中 | 开 | "不增剧情，不改人物关系" |
| 改写 | 强 | 高 | 开 | "保留事实，替换表达" |
| AI 味修正 | 仅反 AI 强 | 高 | 关 | "只修违规点，附违规报告" |

## 七、多层绑定与合并规则

风格可以绑到不同层级：全书、卷、章、某角色视角。合并规则：**越具体越优先**（任务级 > 角色视角级 > 章级 > 卷级 > 全书级）；同字段冲突取高优先级；forbidden 三态 union——任何层级 forbidden 即 forbidden。

## 八、维护操作

- 停用某条特征：enabled 置 false 重新编译
- 调权重：改 weight 重新编译
- 加新样本：扔进样本库，重跑 抽取 → 编译
- 重置：清空特征池（保留 frontmatter）重做抽取

## 自检清单（编译风格卡后）

- [ ] 是否每个特征都有可执行 rule + 正/反例，而非"文笔好""语言生动"式空话？
- [ ] 客观统计是否已标注（句长/段长/标点/对话占比）？
- [ ] 特征是否按 weight 分档编译（不是一刀切全部"必须"）？
- [ ] 反 AI 清单是否分 forbidden/risk/encourage 三段？
- [ ] 是否按任务类型选择了对应装配策略（新章/续写/润色/改写/fix-ai）？
