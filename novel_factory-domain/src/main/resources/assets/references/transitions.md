# 转场与时间线管理

场景转场与时间线管理：硬切、承接物、视角引导等转场技法，时间跳跃的交代方式与时间线矛盾防治。

## 转场的核心认知

转场的目的是**让读者毫不停顿地跟上叙事**，而不是解释主角怎么从 A 走到 B。读者默认场景会变，你只需要标记"变了"，不需要汇报"怎么变的"。

## 四种转场方式

### 1. 硬切（首选）

另起一段/一行，直接写新场景的第一帧：

> （上一场：宗门大殿争吵）
>
> 入夜，戒律堂后的黑瓦上凝了层霜。他伏在瓦沟里，已经等了两炷香。

新场景开头 1-2 句给"时空锚点"（时间词/地点/在场人物），读者立刻重定位。这是网文最常用、最不显痕的方式。

### 2. 承接物转场

用同一个物件/声音/气味缝合两个场景：上一场结尾盯着那枚玉佩，下一场从玉佩在另一个人手里开始。物件像电影里的匹配剪辑。

### 3. 视角引导转场

用角色"所见之物"带出下一场景：他从窗里望见山下驰来的快马——下一场写快马上的来客。用视线代替移动。

### 4. 移动角色过渡

让一个角色物理移动，用他的移动串起空间转换。**最耗字数**，只在需要展示沿途信息时使用，否则改用硬切。

## 转场禁忌

| 禁忌 | 症状 |
|------|------|
| 过渡语冗长 | "他辞别了长老，穿过三重院落，路过藏经阁，又走了两刻钟……" |
| 回顾式衔接 | 新场景开头复述上一场发生的事 |
| 无锚硬切 | 直接上对话，读者不知道谁在说、在哪说 |
| 频繁跳切 | 一章内切 5 个以上场景，读者晕 |

## 时间跳跃

- **跳跃粒度**：日常间歇（吃饭、赶路）直接跳；训练/修炼/等待可跳数日至数月
- **跳后立即锚定**：跳跃后的头几句必须交代"现在过了多久、在哪、发生了什么前置变化"：
  > 一月后。丹田里的灵气已是先前三倍，可瓶颈纹丝未动。
- **跳过的不写，但要有结果**：闭关一月，用"出关时的状态"体现，不用流水账记录每一天
- **大跨度跳跃**（数月/数年）单独成段提示，且跳过的时段里不能藏关键剧情（关键剧情必须正面写）

## 时间线一致性

时间感矛盾是跨章高频问题（"前几日"vs"昨夜"），与记忆账本配合防错：

- 新章动笔时**对齐记忆前缀里的时间点**（timePoint）：当前距上次事件过了多久，季节、昼夜是否连续
- 模糊时间词（"这几日""不久前"）尽量换成**相对锚点**（"大比前三天"），锚点可被账本校验
- 多线并行时，切线回归要**对表**：A 线过了三天，B 线同步过了三天（除非有意错位并埋伏笔）
- 行程时间要合理：步行三日能到的距离，不能有人一夜骑马赶到（除非设定支持）

## 章内多场景切换

- 一章内场景切换 ≤3 次为宜（短章 1-2 次）
- 切换顺序尽量线性推进时间，倒叙插叙要有明确标记（"三日之前"式的提示句或分段符）
- 每个场景都要完整：有锚点、有事件、有出口（钩子或收束），蜻蜓点水的场景合并或删除

## 自查清单

- [ ] 转场是否用了硬切/承接物，没有冗长过渡语？
- [ ] 新场景开头是否有时间/地点/人物的锚点句？
- [ ] 时间跳跃后是否立即交代了跨度与状态变化？
- [ ] 本章时间表述是否与记忆前缀的时间点一致？
- [ ] 多线并行时各线时间是否对表？
