# 套路运用与新鲜感

常见套路的正确使用方式：套路的情绪本质、新鲜感配方、反套路的风险控制，与差异化设计配合使用。

## 套路为什么有效

套路是经过市场验证的**情绪交付程序**：读者熟悉的套路自带预期，作者可以省去解释成本、直接收割情绪。用套路不可耻，可耻的是**不加变化地复读**——读者要的不是"没见过"，而是"熟悉的快感 + 一点意外"。

## 高频套路库与情绪本质

| 套路 | 情绪本质 | 关键交付物 |
|------|---------|-----------|
| 退婚流 | 承诺逆袭 | 那句"三十年河东"兑现的时刻 |
| 扮猪吃虎 | 信息差优越感 | 旁观者态度反转的瞬间 |
| 扮演系统流 | 目标与反馈 | 任务-奖励的节拍器 |
| 重生/穿越 | 先知优势 | 用未来信息改变命运 |
| 马甲揭露 | 身份悬念 | 一层层揭马甲的节奏 |
| 天降金手指 | 越级合法性 | 规则内的关键翻盘 |
| 打脸打怪 | 征服感 | 见证者的震惊 |
| 误会解开 | 心疼与甜 | 错位信息归位的刺痛 |

## 新鲜感配方

老套路翻新的三个杠杆（与 differentiation.md 的五维度配合）：

1. **换皮**：保留程序，替换外壳——退婚的是师父不是未婚妻；系统发布的是烹饪任务
2. **换重心**：把套路的次要元素提为主菜——重生文不写复仇写"补救"（上世欠的人这辈子还）
3. **反向组合**：把两个套路的预期对撞——扮猪吃虎的主角真的只是普通人，靠资源整合赢

每用一次套路，强制自己回答：**这次和上次差在哪？** 差异点要在套路启动的同一章内让读者看见，否则读者默认你在复读。

## 反套路的风险

反套路 = 主动打破读者预期，收益高、风险也高：

- **预期不是凭空破的**：先建立预期（铺垫得越足），打破时冲击越大；随手打破无人会痛
- **读者预期不能白建**：打破了"打脸"预期，要交付更高级的东西（更深的反转/更重的代价），不能只是"什么都没发生"
- **爽文契约要守住**：可以延迟满足、可以加价，但不能赖账——承诺的大高潮不能无疾而终
- 反套路用在大弧点上，**日常爽点守规矩**：章级爽点遵循套路，弧级爆点玩反转

## 套路使用密度

- **同套路间隔**：同一种情绪交付（如打脸）相邻两次至少隔 2 章（对照 emotion-curve 密度表）
- **同章不叠加同源套路**：一章里"退婚 + 打脸 + 马甲揭露"三件套齐上，情绪会互相稀释
- **套路要养**：大套路的兑现需要前期多次小灌溉（退婚流需要先让读者恨足反派）

## 套路自查清单

- [ ] 本章使用的套路，与上一次同套路相比差异点是什么？
- [ ] 差异点是否在套路启动的同一章内可见？
- [ ] 同章是否叠加了多个同源套路？
- [ ] 若使用反套路：前期预期是否铺垫充分？打破后交付了什么替代物？
- [ ] 承诺的高潮是否都在兑现轨道上（没有赖账）？
