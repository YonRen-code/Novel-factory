# 坏→好对照片例库（写作时直接模仿右栏的写法）

每组的 ✗ 例摘自 AI 实际生成正文，✓ 例是改写示范。禁令告诉你"不要什么"，本库告诉你"要什么"——
改写时优先模仿 ✓ 例的句式和详略，而不是在 ✗ 例基础上修修补补。

## 1. 万能副词（不禁/缓缓/微微/仿佛）

✗ 他不禁握紧了剑，缓缓站起身，微微侧头看着她，仿佛有千言万语。
✓ 他握剑起身，看了她三秒，没接话。

## 2. 眼神套话

✗ 他眼神复杂，眸光微动，眼底闪过一丝决绝。
✓ 他的视线在她脸上停了一下，落到门口，又收回来。

## 3. 身体反应套话

✗ 他喉结滚动，深吸一口气，瞳孔骤缩，后背发凉。
✓ 他把手里的笔帽拧紧了又拧开。

## 4. 疼痛注水（同一伤口反复咀嚼）

✗ 疼。钻心剜骨的疼。每一次呼吸都牵动着断裂的肋骨，疼得他眼前发黑。
✓ 他用右手接过碗，左手垂在身侧——从刚才起就没抬起来过。

## 5. 定义式旁白（叙述者跳出来解说设定）

✗ 这就是境界的鸿沟。一只蚂蚁面对大象时的无力感，此刻具象化成了生理上的剧痛。
✓ 他抬剑去挡。剑没抬起来，膝盖先着了地。

## 6. 内心独白冗余（身份/信念反复确认）

✗ 他想起了那个盗矿的探子，想起了她昏迷前的低语，想起了北方天空的漩涡。既然低调苟活换不来安宁，那就把制造麻烦的人全部解决掉。
✓ 他拔剑。守墓三年，第一次把剑尖对着人。

## 7. 骑墙比喻（一个本体挂两个喻体）

✗ 那声音像是哀求，又像是威胁。
✓ 那声音软下来，每个字却都咬得很重。

## 8. 明喻套句（如同/宛如/仿佛句式）

✗ 剑气如同死神的镰刀，宛如黑夜的闪电，瞬间吞噬了一切。
✓ 剑气扫过，三人的护体灵光碎成齑粉。

## 9. 排比三连造势

✗ 他不再犹豫，不再退缩，不再回头。
✓ 他转身走了。

## 10. 环境描写注水（与剧情无关的开场渲染）

✗ 风雪呼啸着掠过荒原，天空阴沉得像一块铁板，远处群山连绵起伏，积雪覆盖着每一寸土地，整个世界一片苍茫。
✓ 雪地里有一串新鲜的脚印，直通洞口。

## 使用方法

- 写作时：每写完一段，自查是否出现左栏模式，出现即按右栏方向改写
- 右栏不是唯一正确答案，是"具体化、行为化、克制化"三个方向的最小示范
- 禁止把右栏的句子原样搬进正文（那会制造新的复读）
