# 情节结构模板（菜单）

常见的故事结构模板索引，用于规划小说章节。写大纲时**先按题材选定一种主结构**，再按该结构的完整模板展开章节计划；各结构的完整模板（含分幕/分节分解表）由动态资料选择器按需从 `references/plot-structure-*.md` 注入。

## 使用规则（必须遵守）

- 必须**选定一种**主结构贯穿全书，并在章节计划中显式声明（如 `structure: 五幕式`）。
- **节拍型结构**（三幕/英雄之旅/悬疑/言情/惊悚/反转/短篇/五幕/七点/救猫咪/故事圈）彼此互斥，只能选其一当主骨架。
- **组织型结构**（多线叙事/起承转合/环形/多线并行/碎片化/套盒）是"怎么排布事件"，可作为叙事组织方式叠加在节拍骨架上。
- 禁止在同一份章节计划中混用不同节拍型结构的里程碑命名（例如把"回落"与"中点"当成同一个节点混写）。

## 章节情节模板

### 单章内部结构

```text
开头（10%）：钩子 + 上下文连接
发展（60%）：事件推进 + 冲突
高潮（20%）：本章最高点
结尾（10%）：悬念钩子 + 下章铺垫
```

### 无效章节结构

```text
开头：漫长铺垫/背景说明
中间：日常活动/对话流水账
结尾：平淡结束/无悬念
```
