# 言情/情感 题材风格

言情、情感、都市爱情类题材的写作风格与纪律：情感递进节奏、关系张力的建立与释放、误会与和解的写法。适用于写正文与修订；规划类场景只取关系线原则，不照搬情感描写条款。

## 言情风格

- **情感递进**：遵循接触→好感→冲突→和解→深入的自然节奏，不急于推进
- **关系张力**：每个阶段都需要合理的阻碍，阻碍来源要多样（性格、立场、误解、外部压力）
- **内心描写**：深入角色内心，展现矛盾和挣扎，但避免大段独白式心理分析
- **互动细节**：用微表情、小动作、不经意的习惯传递情感，比直接告白更有张力
- **对话节奏**：暧昧期对话留白多，甜蜜期对话轻松自然，冲突期对话尖锐但克制
- **场景氛围**：环境描写与情感状态呼应，但不过度使用"下雨=悲伤"类刻板隐喻
- **配角功能**：闺蜜/兄弟角色推动情节发展，不沦为恋爱咨询工具
- **冲突设计**：误会不能靠"一句话就能解释清楚"维持，矛盾要触及核心价值观差异

## 修罗场写作规范

多女主互动场景（修罗场）是言情日常流的核心戏剧张力来源，须遵守以下规范：

- **节奏控制**：修罗场场景内，每个女主的发言/动作轮替不超过 3 次连续独占，必须有其他角色的反应或打断，避免变成单人独白。
- **误会设计**：修罗场的误会必须基于角色已建立的性格和信息差，不能靠"刚好听到半句话"的低级巧合；误会的解开必须付出实际代价（关系裂痕、信任损耗），不能一句话就翻篇。
- **吃醋表现**：每个女主的吃醋方式必须符合其人设，不能全员统一为"冷战+阴阳怪气"。高冷型吃醋→过度公事公办、刻意保持距离；直球型吃醋→直接质问、动作幅度变大；病娇型吃醋→微笑着说威胁的话、暗中做手脚。
- **避免全员降智**：修罗场中角色可以情绪化，但不能做出完全违背其智商和人设的行为；男主的应对必须基于已知信息和系统约束，不能靠"突然变聪明"或"巧合救场"化解。
- **信息差管理**：修罗场的核心是信息不对称，必须明确区分"读者知道的""男主知道的""各女主知道的"三层信息，不能为了制造冲突让角色突然知道不该知道的事。

## 系统流言情规范

含系统面板、好感度、任务提示等 UI 元素的言情题材，须遵守以下规范（与规则 anti-ai-tone.md 第八节联动）：

- **系统提示与情感节奏配合**：系统弹窗应出现在情感转折点（好感度突破阈值、触发特殊事件），不能在日常对话中频繁打断；系统提示出现后必须有角色的具体反应，不能弹完就继续当没发生。
- **惩罚机制的戏剧化使用**：系统惩罚（倒霉、扣分、强制行为）必须有具体的、可被五感感知的表现，且惩罚的后果应影响后续剧情选择；惩罚不能只用来搞笑，必须推动角色关系变化。
- **读心能力的边界**：若系统能读取他人内心，读取内容必须是"一条最真实的内心弹幕"式的碎片化信息，不能是完整的心理分析；男主必须基于碎片化信息做判断，不能因为读心就全知全能。
- **系统升级/消失节点**：系统界面变化（升级、故障、乱码、消失）是重大叙事节点，必须有足够铺垫和后续影响；系统消失后角色的适应过程必须有具体描写，不能瞬间切换状态。
